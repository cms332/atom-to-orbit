## 과학 데이터와 표현

- 데이터: `src/lib/data/science.ts`. 원자 규모의 기준 길이(2a₀), 탁구공, 탁구대, 달, 지구, 목성, 태양의 7개 대상입니다.
- 좌표: `(log10(meters) + 10) / 20`. 양수·유한값, 끝점·중앙·동일 자릿수 간격, 역변환, 단조 순서와 로그상 가장 가까운 대상 선택을 검사합니다.
- 출처 ID, 공식 URL, 실제 확인일, 측정 기준, 근삿값/평균/규격, 원자료 환산식을 분리했습니다. 관련 기사 경로와 출처 ID의 유효성도 검사합니다.
- 지구·달·목성·태양은 체적 평균 반지름 × 2입니다. 목성은 대기 1 bar 수준 기준임을 밝혔습니다. 탁구 규격은 확인한 **ITTF 2025판**임을 명시합니다.
- 원자 항목은 모든 원자의 공통 지름이라는 뜻이 아닙니다. 별도의 거리 데이터는 크기 탐험기에 섞지 않습니다.
- 탐험기 그림은 상징적임을 캡션과 접근성 이름으로 표시합니다. 로그 점의 위치만 수학적 좌표입니다. 지구–달 그림은 지름과 중심 간 거리에 같은 축척을 쓰며, SVG의 실제 지름/거리 비율을 브라우저 테스트로 검사합니다.

## 실행과 남은 범위

```sh
bun install --frozen-lockfile
bun run dev
```

기본 개발 주소: `http://127.0.0.1:5173/`. 빌드 검토는 `bun run build` 후 `bun run preview --port 4173`입니다. 검증 중 로컬 preview와 브라우저를 열었으며 검증용 서버는 마무리 시 종료합니다. 검사 명령과 웹폰트 재생성 방법은 루트 `README.md`에 있습니다.

확인된 기능 오류는 남아 있지 않습니다. Firefox·Safari·실제 iOS/Android와 수동 스크린리더 검증은 수행하지 않았습니다. 두 글은 실제 작성한 로컬 초판이며, 상세 콘텐츠의 후속 편집은 다음 단계입니다. 운영자·연락처는 제공받지 않아 만들지 않았습니다.

실제 호스팅의 404 상태 코드·캐시·보안 헤더·도메인 연결과 실사용자 성능은 향후 배포 단계에서 검증해야 합니다. 이 작업에서는 호스팅 등록, 배포, DNS 변경, 원격 push, 과거 날짜의 커밋을 수행하지 않았습니다. 현재 로컬 버전 전달에 추가로 필요한 사용자 승인 사항은 없습니다.
