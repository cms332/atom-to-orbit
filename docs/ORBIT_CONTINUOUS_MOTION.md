## 재현한 문제

기존 코드에서 `prefers-reduced-motion: reduce`이면 재생 상태를 false로 설정했습니다. 스토리 타이머도 이 재생 상태를 조건으로 사용하여 첫 장면에서 멈췄습니다. Chromium에서 해당 환경을 재현해 16초 전후의 모델 시각이 모두 8.000000년이고 스토리가 ‘우리의 출발점, 지구’에 남아 있음을 확인했습니다. 재현 스크립트: `artifacts/orbit-continuous/before.mjs`.

## 변경

- 태양계 버튼은 전체 태양계를 멀리서 보는 대신 수성·금성·지구·화성 중심의 근접 구도로 시작합니다. 고정 카메라 up축과 황도면 법선으로 시선을 계산해 안쪽 궤도가 수평 타원으로 읽히도록 했습니다. 모바일은 네 궤도가 잘리지 않도록 거리를 맞춥니다. 축소하면 바깥 행성을 볼 수 있습니다. 실제 궤도 거리 비례는 유지합니다.
- 재생 버튼과 정지 상태를 제거했습니다. 기본 도크는 스토리 / 태양계 / 은하 궤적 세 버튼입니다. 스페이스로 정지하던 동작도 제거했습니다. 정상적으로 표시 중인 장면은 항상 움직입니다. 숨겨진 탭·화면 밖에서는 기존 성능 보호를 유지합니다.
- 공통 속도 배율은 1.3입니다. 기본 모델 시간은 0.13년/초, 즉 1년 약 7.7초입니다. 설정의 다른 배속에도 같은 배율을 적용하고 실제 환산 시간을 표시합니다. 태양 표면 회전도 추가했습니다. 태양·행성의 상대 공전 주기나 SI 거리 계산을 따로 바꾸지 않습니다.
- 별도 1초 타이머 대신 실제 렌더링 프레임의 경과 시간으로 이야기를 진행합니다. 장면당 14/1.3 ≈ 10.8초, 카메라 이동 1400/1.3 ≈ 1077ms입니다. 각 장면의 공전·표면 회전·이동 궤적은 계속 갱신됩니다. 마지막 장면은 설명을 남긴 채 움직임을 유지합니다. 이전/다음 화살표와 직접 탐색도 가능합니다.
- 소유자의 명시적 상시 움직임 요청에 따라 모션 감소 설정은 카메라 보간만 생략하며, 천체 운동·자동 이야기 진행을 중단하지 않습니다.
- 모델이 40년에 도달해도 정지하지 않고 0년부터 반복합니다. 이것은 동일한 계산 구간의 재생 반복이며 2040년 이후의 정밀 천체력 예측을 의미하지 않습니다. 사용자 모델 설명에도 반복을 명시했습니다. 0년에서 길이가 0인 궤적 구간은 GPU 선분에 넣지 않습니다.
