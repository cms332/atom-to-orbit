## 원격에 적용할 준비와 남은 단계

README·추가 제외 규칙·SHA에 고정한 읽기 권한 CI·서명/main 보호/릴리스 절차를
준비했다. CI는 배포를 하지 않는다. GitHub에서 실제 CI 실행, 브랜치 보호,
서명 `Verified`, Immutable Releases는 아직 적용·확인한 상태가 아니다.

공개 승인 후 빈 저장소 생성 → 실제 새 커밋 기록 → 기존 이력을 보존한 main 및
검토된 태그 Push → 원격 파일/이력·CI 확인 → main 보호 순서로 진행한다.
서명 키 생성은 개인 키를 채팅에 전달하지 않는 로컬 절차로 별도 진행한다.
패키지가 이미 0.1.9이므로 제안된 `v0.1.0` Release를 자동 발행하지 않는다.
기존 운영 태그 기반 초안을 준비하고 불변 발행 전에 다시 내용을 확인한다.

GitHub 등록은 운영 배포 승인이 아니다. 서버·DNS·다른 서비스는 변경하지 않았고,
Wayback 보존 요청도 아직 하지 않았다.
