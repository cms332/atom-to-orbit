## 구현

`src/lib/components/FootballGlyph.svelte`가 패널 윤곽 한 개와 이음선 경로 세 개를 사용합니다. 원본의 지면 그림자, 강한 검정·흰색 음영과 중복 강조선은 제외했습니다. 종이색 가죽, 짙은 청록 패널, 얇은 이음선과 완만한 구형 음영으로 A2O의 기존 계측 패널에 맞췄습니다.

몸체의 원본 좌표 `(236.97296, 366.478)`부터 지름 `450.1699`를 정규화된 지름 `100`으로 옮깁니다. 정확한 원형 클립으로 가장자리 조각이 원 밖으로 돌출되지 않게 합니다. 각 인스턴스는 Svelte가 생성한 고유 ID를 사용하며, 런타임 외부 이미지 요청이나 필터는 없습니다.

실제 측정값, IFAB 출처와 둘레 69cm에서 환산한 지름은 기존 값을 사용합니다. SVG의 비교 지름은 계속 100 도식 단위이며, 로그 확대·축소 계산은 변경하지 않습니다.
