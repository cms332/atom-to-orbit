## 대상별 관찰과 측정 기준

각 신규 대상마다 최소 한 개의 실제 이미지를 브라우저에 표시하고 관찰했습니다. 실제 로드 결과 15/15와 세 장의 참조 보드는 `artifacts/scale-expansion/references/`에 있습니다. 사진을 사이트에 삽입하거나 트레이싱하지 않고 특징을 간결한 원본 벡터로 다시 구성했습니다.

이전 제안의 “롯데월드타워 건축 높이 555.7 m”는 원자료를 확인해 **최고점 높이(To Tip)**로 바로잡았습니다. 해당 자료의 건축 높이는 554.5 m입니다. 생물의 평균·대표 예시·최댓값, 제품의 명목·규격 치수를 서로 구분합니다. 머리카락 중간값은 인구 평균이 아닙니다.

수치·환산·자료 범위는 `src/lib/data/science-expansion.ts`, 이미지별 관찰 근거와 원본 주소는 `docs/scale-illustration-references.json`에 기록했습니다. 방문자는 `/method/#sources`와 `/method/#illustration-references`에서 두 종류의 자료를 확인할 수 있습니다. 모든 대상에 가짜 관련 기사를 만들지 않고 실제 두 기사만 연결합니다.

## 연속 축척과 표시

- 비교 치수의 화면 길이 = `92 × 10^(log10(SI 미터) − 눈금 지수)` px. 한 decade 이동 시 모든 비교 치수가 1/10이 됩니다.
- `scale-art.ts`의 정규화 좌표 100 단위가 비교 치수입니다. 일반 지름·몸길이는 x 방향, DNA·머리카락·샤프심·건전지의 굵기 및 타워 높이는 y 방향입니다. 세로 비교에는 브래킷을 표시합니다.
- DNA·머리카락·샤프심은 일부 조각의 굵기를 비교합니다. 적혈구의 관찰 각도·세포 내부·표면 무늬는 형태 도식이며 별도의 실측 데이터로 주장하지 않습니다.
- 대상 슬롯 사이를 연속 보간해 현재 대상 주변이 화면에 들어오도록 했습니다. 슬롯 간격은 탐험 배치이며 사물 사이의 실제 거리를 나타내지 않습니다.
- 너무 큰 대상은 실제 크기를 유지하고 농도만 낮춰 등장합니다. 0.15 px 미만인 대상은 표시하지 않으며 가시성을 위해 최소 크기로 부풀리지 않습니다. 거대한 도형도 유한한 SVG 좌표 범위에서 처리합니다.
- 기본 장면 높이 125 px를 유지했습니다. 이름·수치·설명·출처는 22개 항목의 글자 크기를 반영해 공간을 확보하므로 대상을 바꿀 때 패널과 슬라이더가 흔들리지 않습니다. 200% 글자 확대에서는 필요한 공간이 함께 늘어납니다.
- 데스크톱 선택 목록은 스크롤할 수 있고, 모바일 네이티브 선택기·이전/다음·키보드 조작·URL 공유와 22행 정적 표를 유지했습니다. 미세 크기에는 μm 단위를 추가했습니다.
