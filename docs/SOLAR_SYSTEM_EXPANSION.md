# 태양계 8행성 추가 — v0.1.6

구현일: 2026-10-19 (KST). 소유자의 요청대로 포보스·베스타의 이름만 구체화하고, 빠져 있던 수성·금성·화성·토성·천왕성을 추가했습니다. 총 27개 대상 중 태양계의 8행성을 모두 비교할 수 있습니다. 기존 URL 식별자 `phobos`, `vesta`는 유지합니다.

## 크기순과 측정 기준

모든 행성은 NASA Planetary Fact Sheet의 **체적 평균 반지름 × 2**입니다. 거대 행성은 대기 1 bar 기준을 사용합니다. 궤도 거리·태양에서 가까운 순서와 섞지 않습니다.

| 순서 | 행성   | 평균 지름 (km) | 표현                                    |
| ---- | ------ | -------------: | --------------------------------------- |
| 1    | 수성   |        4,879.4 | 충돌구, 밝은 방사상 충돌 흔적           |
| 2    | 화성   |          6,779 | 붉은 표면, 밝은 극관과 어두운 지형 도식 |
| 3    | 금성   |       12,103.6 | 표면을 덮는 밝은 구름층                 |
| 4    | 지구   |         12,742 | 기존 바다·대륙 도식                     |
| 5    | 해왕성 |         49,244 | 기존 짙은 청색 대기·구름 띠             |
| 6    | 천왕성 |         50,724 | 옅은 청록빛 대기와 희미한 구름 띠       |
| 7    | 토성   |        116,464 | 본체의 대기 띠, 앞뒤로 가려지는 고리    |
| 8    | 목성   |        139,822 | 기존 대기 띠                            |

기존 데이터 배열과 통합해 SI 미터 값으로 전체 27개를 정렬합니다. 달 다음은 수성이며, 해왕성 다음은 천왕성입니다. 직접 선택·이전/다음·모바일 선택기·URL 복원·정적 표가 같은 정렬을 사용합니다.

이름 표시는 `화성의 위성 포보스`, `소행성 베스타`로 바뀝니다. 두 대상의 측정값·형태·기존 설명은 유지했습니다.

## 도판과 토성 고리

신규 5개 각각 NASA의 실제 이미지를 브라우저에 표시하고 관찰한 뒤 SVG를 직접 제작했습니다. 참조 파일: `docs/scale-illustration-references.json`; 확인 화면: `artifacts/solar-system/references/board-1.png`. 로드 결과는 5/5입니다. 외부 사진을 사이트에서 불러오지 않습니다.

토성의 116,464 km는 **고리를 제외한 본체**의 체적 평균 지름입니다. SVG 본체 원의 지름 100 단위에 같은 미터 축척으로 다음 중심 기준 고리 반지름을 적용했습니다.

- C 고리 안쪽: 74,658 km.
- B 고리 안쪽/바깥쪽: 91,975 / 117,507 km.
- A 고리 안쪽/바깥쪽: 122,340 / 136,780 km.
- A 고리 바깥 지름 / 본체 평균 지름 = 273,560 / 116,464. 원자료의 적도 반지름 비율과 구분합니다.

고리의 관찰 기울기는 도식이며 현재 실제 관측 각도라는 주장을 하지 않습니다. 주 고리의 앞·뒤가 본체를 가리는 순서를 나눠 그렸습니다. 내부 SVG에서 고리를 잘라내지 않고, 외부 장면 경계에서는 그림을 잘라 페이지 넘침을 방지합니다. 행성의 구름·지형은 원형 경계에 맞게 잘립니다.

비교 치수는 기존 `92 × 10^(log10(SI 미터) − 지수)` px를 유지합니다. 고리 포함 그림 전체를 본체 지름에 억지로 맞추지 않습니다. 선택 대상과 상관없이 같은 지수에서 같은 물리 축척으로 줄어들고 등장합니다.
