# A2O 기사 표시 형식 — 로컬 검토, 2026-10-21

소유자의 요청에 따라 현재 세 기사의 자료·출처를 하단 한곳으로 모으고 공통 템플릿을 맞춘다. 본문은 읽는 흐름을 우선하고, 수치 인용은 작은 각주 번호로 연결한다. 이 문서는 공개 배포 완료 기록이 아니며, 변경 결과를 먼저 로컬로 보여준 뒤 별도의 명시적 배포 요청을 기다린다.

## 공통 흐름

1. 과학 이야기 목록으로 돌아가기, 주제, 제목, 소개. 작성일·읽기 시간은 표시하지 않는다.
2. 핵심 문장, 글의 순서와 본문·도해. 내용에 필요한 수치나 상호작용을 유지한다.
3. ‘직접 탐험해 보세요.’ — 해당 글의 크기/궤도 탐험기 연결.
4. ‘자료 및 출처’ — 기본으로 접힌 참고문헌. 원문 링크·수치 근거·확인일·계산 주석을 모두 보존한다.
5. ‘다음 이야기’ — 나머지 두 실제 기사로 연결.

본문의 길이·단락 수·도해 모양은 주제에 맞게 유지한다. 같은 구조를 사용하기 위해 과학 내용을 늘이거나 지름·거리의 비례 그림을 바꾸지 않는다.

## 자료와 모형 설명

- `ArticleDisclosure.svelte`의 native details/summary를 공통으로 사용한다. 처음에는 접히며, 키보드·터치 및 JavaScript 없는 환경에서도 펼칠 수 있다. 요약 행은 최소 44px이며 반복되는 테두리를 두르지 않는다.
- ‘자료 및 출처’는 기사 하단 한곳에만 표시한다. 절별 자료 메뉴를 반복하지 않는다. 속도 수치의 [1]·[2]·[3] 각주는 하단의 해당 원자료를 바로 펼쳐 연결하며 터치 영역은 최소 44×44px이다.
- 도해 안에는 필요한 ‘모형 설명’만 남긴다. 탐험기 안내 아래의 별도 모형 메뉴는 없애고 그 설명을 하단 자료에 통합한다. 실제 출처 URL·수치 근거·확인일·계산 주석은 보존한다.
- 속도의 단위와 관측 기준, 평균/근삿값, 그래픽 핵심 수치는 본래 위치에 남긴다. 도해의 접근성 설명도 유지한다.
- 인용 링크를 누르면 해당 참고문헌이 있는 접힘 메뉴를 열어 이동한다. 기사 전체에서 각주·도해 안의 링크를 처리하고 직접 해시 주소로 접근해도 자료를 펼친다. 이미 같은 출처 해시를 방문한 뒤 메뉴를 다시 접은 경우에도 재탐색할 수 있다. 외부 링크·새 탭 열기는 일반 링크 동작을 유지한다.
- 다른 기사로 이동하면 기사 DOM을 새로 구성해 이전 글의 펼침 상태가 따라가지 않는다. 출처의 식별자와 원문 URL은 보존한다.

## 세 기사에 적용한 정리

| ---------------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------- |

지구·달 도해는 홈페이지에서도 사용된다. 기사 모드에서만 새 접힘·출처 연결을 적용해 홈페이지의 기존 캡션과 연결 범위를 보존한다. 실제 과학 수치·원자료·Article 메타데이터는 바꾸지 않는다.

제목 아래·목차 위아래·속도 사이·탐험 연결 위아래·다음 이야기 위의 장식 구분선은 사용하지 않는다. 제목과 여백으로 구분하며 본문에서 참고문헌으로 바뀌는 하단 경계에만 가는 선 하나를 둔다. 도해의 외곽과 실제 그래픽 선, 링크의 밑줄은 기능을 유지한다.

## 검증

수정 전 실제 PC/모바일 도해·자료 화면과 구성 비교는 `artifacts/article-format/before-*`에 기록했다. 코드 검사, 세 기사별 접힘·출처 이동·목차·탐험 연결·반응형·접근성·JavaScript 없는 환경의 실제 결과는 아래에 추가한다.

- 타입 검사 오류·경고 0개, 단위 테스트 49개, 린트와 정적 빌드가 통과했다. 초기 정적 빌드의 홈페이지 출처 ID 검사를 통해 공용 도해의 기사 모드를 분리했다. 검사를 끄거나 누락 링크를 허용하지 않았다.
- PC/모바일 브라우저 검사 **18개 통과**, 실패·불안정·건너뜀 0개 (45.9초). 세 기사 모두 기본 접힘, 키보드·포인터 열고 닫기, 인용 링크의 자동 펼침과 같은 해시 재방문, 기사 전환 후 초기화, 원문 URL 보존, 320px 가로 넘침과 Axe 검사를 통과했다. JavaScript 없는 세 기사 출처 이동과 기존 목차·탐험 연결·메타데이터·재생 검사도 통과했다.
- 초기 브라우저 검사에서 Svelte가 추가하는 CSS 클래스와 native summary의 역할을 가정한 선택자 두 곳을 바로잡은 뒤 전체 검증이 통과했다. 해당 초기 보고서는 `initial-local-results.json`, 최종 Playwright 원본 보고서는 `local-results.json`으로 보존했다.
- 실제 모바일 지구·달 도해, 원자 기사 탐험 연결과 펼친 참고문헌 캡처를 열어 확인했다. 전후 감사와 모든 화면은 `artifacts/article-format/`에 있다. 모바일은 Chromium 터치 에뮬레이션이며 물리 기기 검증이 아니다.
- 로컬 미리보기를 갱신해 검토할 수 있도록 한다. 공개 배포·업로드·운영 서버/DNS 변경은 하지 않았다.
