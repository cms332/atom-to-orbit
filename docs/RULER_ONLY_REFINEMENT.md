# 로그 눈금자 정리

작업일: 2026-10-19 (KST).

소유자의 최신 지시에 따라 홈·크기 탐험의 높이가 다른 대상 점, 점에서 내려오는 점선, 세로 플롯 영역과 ‘대상 위치’ 범례를 제거했습니다. 기존 점 플롯을 설명하던 문구도 탐험·방법 페이지에서 정리했습니다. 별도의 세로 배치 해명 문구는 추가하지 않았습니다.

`LogAxis.svelte`는 36px 높이의 로그 눈금자입니다. 10⁻¹⁰–10¹⁰ m의 눈금·단위와 현재 탐색 표시를 유지합니다. 기존 네이티브 슬라이더, 키보드 조작, 정확한 로그 좌표, 원자 기준의 안정된 표시 높이와 SI 데이터·출처 표는 그대로 동작합니다. 이전 마스터 예시의 대상 점 표시는 이번 직접 지시에 따라 변경했으며 마스터 문서 원문은 수정하지 않았습니다.
