# 태양에서 끝나는 탐험 — v0.1.7

> 후속 v0.1.8에서 SVG 영역과 기준 치수를 확대했습니다. 아래 92px는 당시 구현 크기이며, 현재 표시 크기는 [더 넓어진 비교 화면](LARGER_SCALE_SCENE.md)을 따릅니다. 태양에서 멈추는 범위와 거듭제곱 눈금은 유지합니다.

구현일: 2026-10-19 (KST). 소유자의 요청에 따라 홈과 크기 탐험의 오른쪽 끝을 태양의 지름에 맞췄습니다. 기존 10¹⁰ m까지 이어지던 축소 구간을 제거했습니다.

## 좌표와 조작

태양의 기존 원자료 환산값 **1,391,400,000 m**에서 상한을 계산합니다. 과학 데이터와 SVG 축척은 유지합니다.

```text
MIN_EXPONENT = -10
MAX_METERS = Sun.meters
MAX_EXPONENT = log10(MAX_METERS)
position = (log10(meters) - MIN_EXPONENT) / (MAX_EXPONENT - MIN_EXPONENT)
```

정수 지수 눈금은 같은 간격을 유지하고, 탐험 범위는 태양 지름에서 끝납니다. 후속 소유자 피드백에 따라 별도의 `1.39 × 10⁹ m` 끝값 표기·눈금을 제거했습니다. 마지막 레이블은 실제 10⁹ m 위치의 `10⁹ m`로 통일합니다. 태양의 수치는 대상 정보에 표시합니다. 오른쪽 끝에서 태양은 중앙에 놓이며 비교 기준인 92px 지름으로 그려집니다. 이는 기존 `92 × 10^(log10(미터 값) − 지수)` 식의 결과입니다.

소수 지수 끝값에 정확히 도달하도록 네이티브 슬라이더에 `step="any"`를 사용합니다. 화살표 키는 지수 0.01씩, Page Up/Down은 1씩 이동하며 Home/End는 양 끝값으로 이동합니다. 끝에서 오른쪽으로 더 움직여도 값이 늘어나지 않습니다. 태양 선택 주소 `?object=sun`과 직접 끝 지수를 전달한 주소도 원자료 지수를 그대로 복원합니다.

최신 소유자 요청을 명세의 기존 상한보다 우선 적용한 결정이며, 마스터 명세 원문은 보존했습니다. 측정 기준·출처·27개 대상과 반응형 높이 예약은 유지합니다.

## 검증

거듭제곱 표기 정리 후 타입 검사 오류·경고 0개, ESLint·Prettier, 단위 테스트 22개, 정적 빌드가 통과했습니다. 전체 Playwright 실행에서 기존 38개 검사는 통과했습니다. 새 회귀 검사 2개는 단위 공백과 CSSOM의 퍼센트 직렬화 정밀도를 과도하게 제한해 실패했으며, 검사 조건을 브라우저 동작에 맞춘 뒤 재실행해 2/2개가 15.4초에 통과했습니다. 최종 실패·건너뜀·불안정 재시도는 0개입니다. 한 번의 전체 실행에서 40개가 통과했다는 주장은 하지 않습니다.

기록: `artifacts/decade-ruler/full-suite-initial.json`(38개 통과 및 최초 검사 실패), `artifacts/decade-ruler/endpoint-results.json`(수정한 회귀 검사 2개 최종 통과). 이전 태양 끝값 구현의 전체 통과 기록은 `artifacts/sun-endpoint/playwright-results.json`에 보존합니다. 한국어 웹폰트는 118,960 bytes로 재생성했습니다. 홈의 데스크톱·모바일 최종 캡처를 직접 확인했고 localhost:5173에서도 새 표기를 확인했습니다.

- 데스크톱 1440px·모바일 390px에서 홈과 탐험의 End 키·오른쪽 포인터 클릭이 정확한 끝 지수에 도달합니다. 끝에서 오른쪽 키를 눌러도 태양은 같은 크기를 유지합니다.
- 태양의 표시 치수 92px와 눈금 커서 x=1000을 확인합니다. 마지막 거듭제곱 레이블은 그 값의 실제 위치에 두며, 정수 지수 눈금의 간격과 정확한 좌표를 검사합니다.
- 태양 주소 새로고침·기존 URL/히스토리·27개 SVG의 실제 10배 축소·고정 높이·내부 링크·자동 접근성·200% 글자 확대·JavaScript 없는 콘텐츠가 통과했습니다.
- 새 끝값 화면의 가로 넘침과 브라우저 런타임 오류는 0개입니다. 외부 출처 값은 변경하지 않았으며, 이번 작업에서 외부 링크 전체를 다시 검사했다는 주장은 하지 않습니다.
