## 반영한 코드

수정 대상은 사전에 안내한 `src/lib/styles.css`와 `src/routes/+page.svelte`입니다. 파일 삭제나 실행 의존성 추가는 없습니다.

| 기존 상태                                            | 이번 반영                                                             | 목적                                                   |
| ---------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------ |
| 홈 일부 그림 영역과 원고 목록의 열이 bare `1fr`      | `minmax(0, …)` 그리드 열 사용                                         | 내용의 최소 너비 때문에 열이 줄어들지 못하는 위험 완화 |
| 제목의 긴 단어나 문자열에 일반적인 줄바꿈만 적용     | 제목에 `min-width: 0`, `overflow-wrap: anywhere` 추가                 | 좁은 화면과 글자 확대에서 긴 제목 대응                 |
| 주제 링크의 이름에 도식·설명·수치까지 함께 포함      | 제목 ID를 `aria-labelledby`, 설명·범위 ID를 `aria-describedby`로 연결 | 링크의 이름과 부가 설명 구분                           |
| 포커스·누름·링크 테두리 색이 사용 위치에 직접 기재됨 | 기존 값을 `--focus`, `--primary-pressed`, `--link-rule`로 명명        | 기존 색을 유지하면서 스타일 관리 일관성 보강           |

배경과 측정 패널의 대비, 정식 브랜드 이름, 자체 SVG, 과학 수치와 출처, 로그 축 계산, 기존 선택 메뉴 아웃라인 제거는 유지했습니다. 전역 overflow를 감춰 실제 넘침 문제를 숨기지 않았습니다.
