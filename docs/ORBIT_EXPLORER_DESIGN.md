# 궤도 탐험: 기능 설계와 독립 구현

> 첫 구현의 설계 기록입니다. 소유자가 재진입·복잡한 조작부·시각 품질을 지적하여 같은 날 화면을 다시 구성했습니다. 현재 경험과 검증은 [간소화 재설계](ORBIT_EXPLORER_REFINEMENT.md)를 우선합니다. 아래의 수학 모델은 유지하며, 시작 버튼·상시 패널·외부 이미지 미사용 설명은 첫 버전에만 해당합니다.

설계일: 2026-10-20 (KST). 공개 배포 없이 로컬에서 개발합니다.

## 설계 해석

Reading this as: 한국어 과학 독자를 위한 궤도 체험 페이지, 기존 Editorial Observatory의 종이색 편집 화면과 청록 계측기를 보존하는 방향.

Taste 설정은 DESIGN_VARIANCE 5 / MOTION_INTENSITY 2(편집 화면), 6(사용자가 시작한 과학 시뮬레이션) / VISUAL_DENSITY 4입니다. 공통 테마·과학 도판·기술 스택은 마스터 명세와 프로젝트 전용 Taste 지침을 우선합니다. 소유자의 이번 요청으로 독립 Three.js 시뮬레이터를 추가합니다. 기존 크기 탐험기는 유지합니다.

## 레퍼런스 관찰

[The Helix](https://mathew-harvey.github.io/TheSolarSystem/)의 실행 화면을 브라우저에서 직접 확인했습니다. 시작 화면, 스토리 시작, The Clockwork, The Reveal, The Vortex를 조작했습니다. 공개 설명도 확인했습니다. 소스 코드·셰이더·모델·텍스처를 복제하거나 다운로드하지 않았습니다.

- 가까운 지구에서 태양계 전경, 이동 궤적으로 시야를 넓히는 카메라가 설명의 역할을 합니다. 단계 선택은 자동 스토리를 중단해 직접 탐색으로 이어집니다.
- 시간 배속과 태양의 이동 속도는 독립 조작입니다. 정지한 태양과 이동하는 태양을 비교하면 좌표계 차이가 드러납니다.
- 행성마다 색을 달리한 이동 궤적, 현재 공전선, 이름을 각각 켜고 끌 수 있습니다. 드래그·휠로 자유 시점을 탐색합니다.
- 실제 속도로 바꾸면 궤적이 길어집니다. 기본값은 읽기 쉬운 시각적 근사입니다. A2O에서도 근사값을 현재 화면에 직접 표시합니다.
- A2O는 국부 태양계의 좌표계 비교에 집중합니다. 이웃 은하·우주 전체로의 확장, 달, 인터넷의 원뿔형 소용돌이 표현은 이번 범위에 포함하지 않습니다.

## 과학 모델의 경계

- 행성은 [JPL Approximate Positions, Table 1](https://ssd.jpl.nasa.gov/planets/approx_pos.html)의 J2000 황도 궤도요소와 세기당 변화율로 계산합니다. 케플러 방정식은 뉴턴 반복법으로 풉니다. 계산 범위는 J2000부터 40 율리우스년까지로 제한하여 해당 표의 유효 구간(1800–2050) 안에 둡니다. 실제 오늘의 하늘이나 정밀 천체력이 아닙니다. 지구는 지구–달 질량중심의 근사입니다.
- 1 AU = 149,597,870,700 m: [IAU 정의](https://iauarchive.eso.org/public/themes/measuring/). 1 율리우스년 = 365.25일. 궤도 거리는 선형 AU를 유지합니다. 작은 천체는 식별용 표식으로 확대하며 실제 지름 비례를 주장하지 않습니다.
- 태양의 은하 공전 속도는 약 230 km/s를 대표값으로 채택합니다. [NASA 태양계 설명](https://science.nasa.gov/solar-system/solar-system-facts/)의 828,000 km/h와 일치합니다. 은하 기준에서는 J2000 태양 위치를 국부 원점으로 두고 은경 90도 방향으로 등속 이동시킵니다. 수십 년 동안의 국부 접선 근사이며 은하 전체 중력장·태양의 고유운동·수직 진동·태양계 질량중심 흔들림을 적분하지 않습니다.
- J2000 황도 → 적도(기울기 23.43928도, JPL) → 통상적인 ICRS 은하 축의 회전행렬을 적용합니다. 은경·은위 좌표의 정의는 [Astropy 좌표 문서](https://docs.astropy.org/en/stable/coordinates/)를 참고합니다. Three.js에서 은하 북쪽이 +Y가 되도록 오른손 좌표를 배치합니다. 공전면이 이동 방향과 수직인 원뿔로 그리지 않습니다.
- 은하 기준 궤적은 r행성(t) + v태양·t, 태양 중심은 r행성(t)입니다. 렌더링만 현재 태양 위치로 재중심화합니다. 은하 시점의 카메라가 태양을 추적한다는 점을 UI에 표시합니다. 기준 전환은 물리적 상대 위치·모델 시간을 바꾸지 않습니다.
- 실제 속도 비율(230 km/s)과 시각적 강조(초기 1/20)를 구분합니다. 후자는 태양 이동 성분만 줄입니다. 시간 배속은 모든 운동에 공통 적용합니다. 개별 행성 속도나 궤도 거리를 몰래 변형하지 않습니다.
- 궤적은 현재부터 선택 기간 전까지의 계산 표본이며 0년 이전을 만들지 않습니다. 수성 공전의 앨리어싱을 막도록 기간에 맞춘 표본수를 사용하고 상한을 둡니다.

## 구현·성능·접근성

회전 상수는 [ERFA의 Hipparcos 기반 ICRS–은하 행렬](https://github.com/liberfa/erfa/blob/master/src/icrs2g.c)을 확인하여 부동소수점 정밀도 안에서 사용합니다. 원문과 전체 라이선스는 `docs/reference-assets/erfa-icrs2g.c` 및 `/licenses/erfa-icrs2g.txt`에 보존합니다. The Helix의 프로그램은 사용하지 않습니다. JPL 원자료의 AU 표기는 남기되 긴반지름의 SI 미터값과 출처 ID를 별도로 보관하고 여기서 렌더 단위 AU로 환산합니다. 자료 확인일은 2026-10-20입니다.

Svelte SSR 설명/표 → 사용자가 3D 시작 → 로컬 번들 Three.js 지연 로드. CDN·계정·서버 API·외부 텍스처가 없습니다. Three.js는 MIT, 타입 정의는 MIT이며 라이선스 고지를 로컬에 보관합니다. 도형·표면·카메라·UI는 자체 작성합니다.

픽셀 비율 제한, 재사용 BufferGeometry, 제한된 궤적 표본, 화면 밖/백그라운드에서 정지, 30fps 상한을 적용합니다. 렌더러·이벤트·관측자·GPU 자원을 경로 이탈 때 정리합니다. WebGL 실패·컨텍스트 손실 시 2D 도식과 설명/자료 표를 유지합니다. 천체 선택·시점 프리셋·회전·확대 버튼은 키보드로 사용할 수 있습니다. 모션 감소 환경은 정지 화면에서 시작하고 카메라는 즉시 전환합니다.

## 검증 계획

수학 단위 검사(케플러 잔차, J2000 표준 위치, 거리 보존, 변환행렬 직교성, 속도 환산, 표시 모드·좌표계 동치), 실제 WebGL UI 검사(재생·정지·시점·시간·행성별 궤적·카메라·스토리·재설정), WebGL 불가와 no-JS 대체 화면, 데스크톱/모바일/200% 글자·접근성·기존 페이지 회귀 검사를 수행합니다. 실제 실행 결과는 완료 후 진행 문서에 기록합니다.
