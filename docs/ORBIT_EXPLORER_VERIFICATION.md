# 궤도 탐험 구현·검증 기록

> 이 문서는 소유자가 개선을 요청한 첫 버전의 검증 기록입니다. 현재 UI·텍스처·자동 진입과 새 검증 결과는 [간소화 재설계](ORBIT_EXPLORER_REFINEMENT.md)에 기록합니다. 이 문서의 시작 버튼과 이전 캡처는 현재 화면이 아닙니다.

2026-10-20 (KST). 로컬 구현이며 공개 배포·DNS 변경은 하지 않았습니다.

## 구현한 경험

홈의 세 진입 링크와 데스크톱·모바일 헤더를 **크기 탐험하기 → 궤도 탐험하기 → 과학 이야기 읽기** 순서로 정리했습니다. `/orbit/`를 실제 정적 페이지와 사이트맵에 추가했습니다. 기존 크기 탐험기와 제거된 `/method/`, `/updates/`, `/about/`의 404 상태를 유지합니다.

새 페이지는 다음을 제공합니다.

- 태양·수성부터 해왕성까지 여덟 행성의 독립 Three.js 장면.
- JPL Table 1의 요소·변화율과 케플러 방정식으로 계산하는 공전. SI 미터 기반 긴반지름, 출처 ID와 원자료 AU 값을 함께 보관합니다.
- 태양 중심 / 은하 축 기준·태양 추적 카메라, 모든 행성에 동일하게 적용하는 시간 배속과 모델 시간 탐색.
- 태양 이동 성분 0–100% 조절, 기본 1/20의 시각적 강조와 실제 대표 속도 230 km/s 모드. 거리는 선형 AU 비례이며 천체 표식 크기는 확대합니다.
- 행성별 과거 궤적 선택, 공전 기준선·이름 전환, 천체 선택·추적, 드래그·휠·핀치 자유 시점, 키보드로 작동하는 프리셋·회전·확대 버튼.
- 여섯 단계의 한국어 설명과 카메라 전환, 단계별 직접 선택·자동 진행, 사용자의 조작 시 자동 이야기 중단, 초기화.
- 3D 시작 때만 엔진 로드, 모션 감소 시 정지 화면·즉시 카메라 전환, WebGL 불가·컨텍스트 손실·JavaScript 비활성 환경의 설명·2D 도식·정적 자료 표.

레퍼런스 관찰, 난이도와 수학 모델의 경계는 [설계 문서](ORBIT_EXPLORER_DESIGN.md)를 참고합니다. The Helix 소스·셰이더·텍스처는 사용하지 않았습니다. Three.js MIT와 ERFA 회전 상수 원문의 전체 고지를 `/licenses/` 및 내부 원자료 폴더에 보관했습니다.

## 화면·성능 증거

`artifacts/orbit-explorer/`에 18개 PNG, 화면 수집 스크립트와 `render-audit.json`, 최종 원시 브라우저 결과 `final-results.json`을 저장합니다. 단계 1·3·5·6, 시각적 강조와 실제 속도 비율, 전체 패널, 200% 글자 화면을 포함합니다. `1440-helix.png`, `390-helix.png`, `1440-chapter-5.png`, `390-final-panel.png`이 대표 화면입니다.

1440px·390px 실제 브라우저에서 시작 전 3D 엔진 요청이 없고 시작 후 요청되는 것을 확인했습니다. 엔진을 포함한 지연 로드 청크는 564,365 bytes, gzip 141,913 bytes입니다. 빌드의 500kB 청크 경고는 남아 있으며 초기 페이지 로드와 분리했습니다. 해당 정지 장면에서 렌더 호출 28회·삼각형 8,524개를 기록했습니다. 이는 특정 장면의 렌더 비용이며 전체 장면의 최대값이나 실제 모바일 기기의 FPS 측정치가 아닙니다.

코드는 DPR 상한(모바일 1.5 / 데스크톱 2), 30fps 렌더 상한, 약 12Hz 궤적 갱신, 재사용 GPU 버퍼와 표본 상한을 사용합니다. 화면 밖·백그라운드에서는 시뮬레이션과 렌더를 멈추고 경로 이탈 시 GPU 자원·이벤트·관측자를 정리합니다. 실제 iOS/Android 기기의 발열·배터리·장시간 FPS와 실제 사용자 Core Web Vitals는 아직 측정하지 않았습니다.

## 모델의 실용적 한계

J2000부터 40 율리우스년까지의 근사 위치와 국부 등속 은하 이동을 보여주는 교육용 체험입니다. 정밀 천체력, 은하 중력장/N체 적분, 달의 독립 공전, 태양 고유운동·수직 진동·은하 궤도의 곡률은 이번 모델에 포함하지 않습니다. 지구는 지구–달 질량중심 근사이고 천체 표식 크기는 실제 지름 비례가 아닙니다. 이 구분은 페이지의 설명·자료 영역에도 표시합니다.

## 재현

```powershell
bun run check

bun run test
bun run build
$env:PLAYWRIGHT_JSON_OUTPUT_NAME='artifacts/orbit-explorer/final-results.json'

```
