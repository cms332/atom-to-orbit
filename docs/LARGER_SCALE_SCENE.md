# 더 넓어진 비교 화면 — v0.1.8

구현일: 2026-10-19 (KST). 소유자가 지적한 얇은 SVG 영역을 홈과 크기 탐험 양쪽에서 확대했습니다. 기존 Editorial Observatory의 색·타이포그래피·로그 눈금과 태양 끝값은 유지합니다. Taste의 보존형 개선 기준을 적용하며 과학 수치·비율은 별도 계산과 검증을 따릅니다.

## 크기와 반응형 규칙

기존 SVG 높이는 125px, 기준 치수는 92px였습니다. 현재는 캔버스 폭으로 하나의 공통 기준 치수를 정하고 모든 대상과 물리 기준자에 함께 적용합니다.

```text
referencePixels = min(180, canvasWidth / 2.6)
canvasHeight = referencePixels + 96
renderedLength = referencePixels × 10^(log10(SI meters) − exponent)
```

| 조건                       | 기준 치수 | SVG 높이 |
| -------------------------- | --------: | -------: |
| 넓은 화면                  |     180px |    276px |
| 390px 모바일, 캔버스 312px |     120px |    216px |
| 320px 모바일, 캔버스 242px |   약 93px | 약 189px |

넓은 화면의 기준 치수는 약 1.96배, 390px 모바일에서는 약 1.30배입니다. 모바일의 확대량을 제한해 토성의 고리 전체가 들어갈 여백을 확보합니다. 대상을 바꿀 때마다 맞춤 확대하지 않으므로 같은 화면에서 모든 대상의 실제 크기 비율과 10배 축소 규칙이 유지됩니다. 화면 폭이 일정하면 캔버스 높이도 일정합니다.

컨테이너 단위 CSS와 카메라가 같은 상수를 사용해 자바스크립트 실행 전부터 반응형 높이를 확보합니다. 초기 폭을 측정한 뒤 패널이 줄어드는 현상을 피하며, 자바스크립트를 끈 홈·탐험 화면의 높이도 검증합니다. 새 Lighthouse 점수나 실제 이용자 CLS 수치를 주장하지는 않습니다.

기준 치수인 대상의 위쪽에는 40px, 아래쪽에는 기준자를 포함한 56px 공간이 생깁니다. 물리 기준자·시야 너비도 새 축척에서 계산합니다. 인접 그림 간격을 넓혔고, 큰 원형 표면의 간략 투영은 캔버스 폭 5배 이후에 사용합니다. 렌더링 한계는 기존 6배로 유지합니다. SI 값·출처·측정 기준·거듭제곱 눈금은 바꾸지 않았습니다.

이전 92px 기준을 설명하는 과거 구현 보고서보다 이 후속 기록이 현재 표시 크기를 설명합니다.

## 검증
