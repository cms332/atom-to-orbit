# A2O v0.1.3 — 누적 변경 검증

> 후속 수정: 홈 탐험기의 대상 변경 시 높이 변화를 수정했습니다. 최신 회귀 검사 포함 30개 Playwright 결과와 비교 캡처는 [홈 탐험기 높이 안정화](STABLE_EXPLORER_HEIGHT.md)를 참고합니다. 아래 28개 결과는 이 후속 수정 이전의 검증 기록입니다.

검증일: 2026-10-19 (KST). 대상은 Emil·Taste·Hallmark·Impeccable·Anthropic 지침을 참고한 누적 편집 화면 변경과 이번 검증 보완입니다. 공개 배포·DNS 변경·원격 push는 수행하지 않았습니다.

## 자동 승인 오류

최초 타입 검사 요청은 자동 승인 검토 시간 초과로 실행되지 않았습니다. 허용된 재시도도 `Selected model is at capacity`로 실행 전에 중단됐습니다. 코드의 안전성 거절이 아니라 검토 서비스의 실패라는 도구 응답을 확인했습니다.

앱 로그는 이 채팅의 실제 정책을 `on-request` / `auto_review`로 기록했습니다. 로컬 config.toml의 `approval_policy = "never"`와 달랐으므로 로컬 파일만 바꾸면 해결된다고 판단하지 않았습니다. [OpenAI 공식 문서](https://learn.chatgpt.com/docs/sandboxing/auto-review)는 자동 검토를 별도 검토 에이전트로 설명하며, 관리 설정이 로컬 설정보다 우선함을 명시합니다. [설정 명세](https://learn.chatgpt.com/docs/config-file/config-reference)에서 검토 모델만 교체하는 설정은 확인하지 못했습니다.

사용자에게 수동 승인 전환을 요청한 응답 이후, 필요한 승인 요청 명령이 정상 실행됐습니다. 그 뒤 타입 검사·단위 테스트·빌드·Playwright·글꼴 재생성과 추가 링크 검사가 완료됐습니다. **검증 실행의 차단은 해소됐지만 자동 검토 서비스의 영구 복구나 실제 검토 모델 변경을 확인한 것은 아닙니다.** 전역 설정·승인 정책·파일 권한을 변경하거나 보호 장치를 해제하지 않았습니다.

기본 권한에서 별도로 발견한 도구 문제도 구분했습니다. esbuild의 상위 폴더 접근 제한 때문에 기본 빌드/테스트는 시작하지 못했습니다. Vite의 공식 runner 설정 로더로 단위 테스트는 실행 가능했지만 SvelteKit 내부 빌드 단계는 같은 제한을 받았습니다. 최종 결과는 runner 대체 실행이 아닌, 승인 후 실행한 기존 정식 스크립트의 결과입니다.

## 이번 검증에서 수정한 내용

- Prettier의 입력을 실제 소스·테스트·문서·정적 파일·설정으로 한정했습니다. 기존 `.prettierignore`와 함께 임시 다운로드 `.tmp/fonttools/bin`을 순회하다 실패하던 문제를 해결했습니다.
- 링크 검증에 실제 목차 대상, 빈 fragment, 이미지 로딩과 페이지별 브라우저 오류 확인을 추가했습니다. 이미지 검사에서 발견한 DOM 타입 오류는 `HTMLImageElement` 확인으로 수정했습니다.
- 모바일 선택 메뉴의 포커스 아웃라인 제거를 실제 computed style로 검증했습니다. 이 요청은 유지하며 나머지 컨트롤의 키보드 포커스는 보존합니다.
- Playwright 결과를 JSON으로 보관하고, CI 검증에서는 기존 preview 서버 재사용을 막았습니다. 이번 실행은 `CI=1`로 새 서버를 시작했습니다.
- 추가 Playwright 스크립트 `scripts/audit-preview.mjs`로 모든 로컬 페이지와 자산, 외부 원자료를 확인했습니다. Windows에서 최종 실행에는 Node 런타임을 사용했습니다.
- 실제 개선을 `/updates/`에 v0.1.3으로 기록하고, 한국어 문구를 반영한 OFL 글꼴 서브셋을 100,700바이트로 재생성했습니다.

자동화 범위에는 로그 슬라이더 키보드 조작, 정확한 SI 표시, 선택 상태와 URL의 동기화, 새로고침·뒤로가기·앞으로가기, 이력을 쌓지 않는 연속 조작, 기사 필터와 제목/링크 의미, 모바일 메뉴 Escape와 포커스 복귀, 목차 이동, JavaScript 비활성 읽기, 200% 글자 확대, 동작 줄이기 설정, 지구–달 비례 도형 검사가 포함됩니다.

반응형 추가 너비는 320/360/375/414/768/1280/1920px이며 홈·탐험·기사 목록·지구–달 본문을 확인했습니다. 기본 캡처는 데스크톱 1440×1000, 모바일 390×844입니다. 새 홈·탐험·기사 목록/본문·방법 화면을 직접 살펴보았고 겹침·잘림을 발견하지 못했습니다.

타입 검사에는 SvelteKit의 `root` 옵션 재설정 안내, Playwright에는 Node의 색상 환경 변수 안내가 출력됐습니다. 소스 진단 오류나 실패는 아닙니다. Lighthouse는 이번에 재실행하지 않았으며 과거 점수를 최신 변경의 점수로 제시하지 않습니다. 자동 접근성 검사와 Chromium 화면 검증이 모든 보조 기술·브라우저를 보장하지는 않습니다.

## 증거와 재실행

- `artifacts/verification-2026-10-19/playwright-results.json`: 28개 테스트와 통계.
- `artifacts/verification-2026-10-19/link-and-display-audit.json`: 각 페이지 크기·폰트 로딩·요청 오류, 내부/외부 URL 상태.
- 같은 폴더의 `desktop-*.png`, `mobile-*.png`: 주요 7개 페이지 전체 화면과 9개 경로 뷰포트 캡처, 총 32개 PNG.
- `playwright-report/index.html`: Playwright HTML 보고서.
- `artifacts/desktop-text-200.png`, `artifacts/mobile-text-200.png`: 이번 실행의 본문 글자 200% 화면.

추가 검사는 새 빌드를 만든 다음 로컬 preview를 열고 `node scripts/audit-preview.mjs`로 실행합니다. 기본 주소는 `http://127.0.0.1:4173`이며 `A2O_PREVIEW_URL`로 변경할 수 있습니다. 검사 결과의 외부 HTTP 200은 확인 시점의 접속 가능성을 뜻하며 원자료 내용의 재감수나 향후 가용성을 보장하지 않습니다.

기존 개발 서버 `http://127.0.0.1:5173/`의 홈과 `/updates/`가 HTTP 200이고 최신 v0.1.3이 표시됨을 확인했습니다. 추가 개발 서버는 이미 사용 중인 포트에서 strictPort로 종료됐으며 기존 서버를 유지했습니다.

이전 문서에 기록한 GitHub 다운로드/스킬 설치 미완료 상태는 별도입니다. 이번 검증은 이미 존재하는 코드의 정상 동작을 확인한 것이며, 다운로드하지 못했던 저장소를 설치했다고 주장하지 않습니다.
