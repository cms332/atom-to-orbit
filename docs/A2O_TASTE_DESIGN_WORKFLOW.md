## 사용 범위

공용 스킬 목록의 `design-taste-frontend`를 A2O의 홈·편집 화면 개선에 사용합니다. 특정 프로젝트 전용으로 설치된 스킬이 아니며, 이번 작업 이전 A2O 진행 기록에서는 직접 적용한 이력을 확인하지 못했습니다. 다른 프로젝트의 사용 이력은 조사하거나 추정하지 않았습니다.

기준 스킬: `C:/Users/Qoo/.codex/skills/taste-skill/SKILL.md`. 별도의 `gpt-taste`는 GSAP·강한 움직임을 중심으로 하므로 이번의 차분한 과학 편집 화면에는 선택하지 않았습니다. 저장소 `AGENTS.md`에도 이 사용 범위를 추가했습니다.

## Design Read

한국어 독자를 위한 출처 중심 과학 편집 사이트의 보존형 개선입니다. 종이색 바탕, 짙은 잉크색, 청록 계측 패널을 유지하고 제목·여백·주제 탐색의 위계를 정리합니다.

- `DESIGN_VARIANCE: 5` — 기존 좌우 영웅 영역과 편집형 배치를 유지하며, 반복 카드 대신 주제 목록으로 리듬을 구분합니다.
- `MOTION_INTENSITY: 2` — 자동·스크롤 애니메이션을 추가하지 않습니다. 기존의 짧은 포인터 피드백만 유지합니다.
- `VISUAL_DENSITY: 4` — 짧은 안내와 충분한 읽기 간격을 사용하되 장식 때문에 화면을 길게 늘리지 않습니다.

## 마스터 명세와의 관계

스킬의 첫 원칙인 문맥 해석과 보존형 개선을 적용합니다. 공통 기본값이 A2O 명세를 덮어쓰지 않습니다.

- React/Next.js·Tailwind 기본값 대신 기존 Svelte 5·SvelteKit 2·CSS 구조를 유지합니다.
- 임의 사진·AI 과학 그림 대신 명세가 요구한 실제 작동 탐험기와 명시적으로 상징적임을 밝힌 기존 SVG를 사용합니다.
- 전체 테마 통일이나 새 다크 모드보다 명세의 종이색 화면과 짙은 계측 패널 조합을 우선합니다.
- 일반적인 기호·팔레트 제한으로 정식 이름 `A2O — Atom to Orbit`와 승인된 청록·구리색을 변경하지 않습니다.
- 데이터 표와 수학적 로그 축은 스킬의 적용 범위 밖입니다. 정확성과 접근성은 마스터 명세와 과학 데이터 테스트를 따릅니다.
- 선택 메뉴의 아웃라인 제거는 소유자의 최신 직접 요청대로 유지합니다.

## 검증 상태

코드 변경과 정적 검토는 수행했습니다. 새 의존성이나 실행 스크립트를 추가하지 않았습니다. 모바일에서는 주제 목록을 두 열의 작은 도식·본문으로 재배치하고 수치 범위를 본문 아래에 표시하도록 명시했습니다.

현재 `bun run check` 실행 요청이 자동 승인 검토의 `Selected model is at capacity` 오류로 실행되지 않았습니다. **타입 검사·린트·테스트·빌드·Lighthouse·변경 후 브라우저 확인을 통과했다고 주장하지 않습니다.** 기존 v0.1.2의 검사·화면 결과는 이번 수정의 결과가 아닙니다.

실행 환경이 복구되면 필수 검사와 데스크톱 1440px·모바일 390px 화면을 확인하고, 360/768/1280/1920px 및 200% 글자 확대에서 주제 목록·버튼·수치의 넘침을 검사해야 합니다. 그 전까지 이번 변경의 시각 검증은 미완료입니다. 이전 Emil 스킬 파일 추가와 검증 미완료 상태도 별도로 남아 있습니다.

공개 배포·DNS 변경·원격 push는 하지 않았습니다.
