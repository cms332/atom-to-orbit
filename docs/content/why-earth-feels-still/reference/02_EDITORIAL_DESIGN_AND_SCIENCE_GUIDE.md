# A2O 콘텐츠 제작 가이드 — 왜 우리는 제자리에 있다고 느낄까?

기준 문서: `01_ARTICLE_PUBLISH_READY.md`  |  대상 프로젝트: https://a2o.kr  |  연결 콘텐츠: `/orbit/`

## 1. 콘텐츠의 목적

**독자의 질문:** 태양계가 엄청나게 빠르게 움직이는데 왜 내 몸은 아무 일도 없는 듯 느끼는가?

**하나의 결론:** '움직이지 않는 것'과 '움직임을 느끼지 않는 것'은 다르다. 기준좌표계, 관성, 공통 중력 가속도를 이해하면 지구에서의 일상적 평온함과 은하 속 움직임이 동시에 이해된다.

**학습 성취 목표:**
1. 속도는 기준에 따라 달라지는 값이며, 속도 자체와 가속/힘의 감각을 구분한다.
2. 지구의 태양 공전은 방향이 변화하는 가속 운동임을 설명한다.
3. 지구와 관찰자가 태양 중력 아래 함께 운동하므로 태양 공전 때문에 별도의 쏠림을 느끼지 않는 이유를 이해한다.
4. 태양 기준 궤도와 은하 기준 궤도가 다르게 보이는 것을 실제 A2O `/orbit/` 시뮬레이터에서 확인한다.

**톤:** 짧고 깨끗한 관찰(물컵·창밖) → 질문 → 수치 → 정확한 설명 → 카메라 시점 전환 → 담담한 여운. 지나친 의인화, 감상적인 추상어, 공포심 조장 금지.

## 2. 화면 구성 및 원고 배치

### A. 상단 히어로(기사 시작)
- 분류 칩: `태양계와 우주 / 움직임의 물리학`
- 제목: `태양은 움직이는데, 왜 우리는 제자리에 있다고 느낄까?`
- 소개 1줄: `움직이는 지구 위에서 멈춰 있다고 느끼는 이유.`
- 배경은 기존 A2O 기사 스타일의 밝은 종이색·차콜 텍스트. 우주 배경 전체화면 영상, 스톡 이미지는 피함.
- 단순 SVG 키비주얼: 고정된 물컵을 중심으로 `지구 / 태양 / 은하` 세 좌표선이 희미하게 확장되는 추상화. '3개의 궤도가 실제로 같은 평면에 있다'고 오해시키지 않도록 도식 표시.

### B. 속도 카드(3개, 본문 1~2단락 이후)
- 지구 자전: `1,670 km/h` — `적도 지표면 기준`
- 지구 공전: `29.78 km/s` — `태양 중심 평균`
- 태양계 은하 공전: `약 230 km/s` — `은하 중심 기준 근삿값`
- 모바일 1열, 720px 이상 3열. 숫자 tabular-nums.
- 출처에 연결되는 주석/툴팁 제공; 동일한 '속도계'로 나열하면서 직접 합산 가능한 값처럼 보이지 않도록 공통 보조문구 삽입: `각 속도는 기준계가 다르며, 단순 합산할 수 없습니다.`

### C. ‘기차 안의 물컵’ 관성 설명(짧은 도식)
- 흰색/연한 회색 SVG 그림으로 `일정하게 이동` vs `급제동` 2컷.
- 컵의 움직임은 정성적 비유이며 지구 공전 전체(원운동)를 설명하는 완전한 모형은 아님을 짧게 명시.
- 본문의 바로 다음 단락에서 '공전은 가속 운동'이라는 점을 반드시 보완.

### D. 가장 중요한 과학 도해 — 기준좌표계 비교

**기본형(우선):** 좌우 2패널, 모바일 세로 적층.
- 왼쪽 `태양 기준`: 태양 주변 지구 공전을 닫힌 곡선으로 표현.
- 오른쪽 `은하 기준`: 태양 이동 경로에 공전 성분이 더해진 지구의 궤적. 시간 방향 표시. 지구가 태양 뒤에서만 따라가는 그림은 금지.
- `개념도 · 길이·속도 비례 아님` 고지 필수.
- 회전 궤도면과 진행방향의 관계 때문에 실제 3D 형태는 보는 각도에 따라 달라짐. 도식을 특정 나선 형태가 실제 유일한 궤적으로 보이게 하면 안 됨.
- 아래 CTA: `궤도 탐험에서 시점을 바꿔 보기 ↗` → `/orbit/`.

**가능하면 추가하는 인터랙션(선택):**
- `태양 기준 / 은하 기준` 토글. SVG 또는 Canvas 2D 사용 가능. 새 Three.js 씬을 별도로 로드할 필요는 없음.
- 토글은 *같은 물리 운동*을 다른 좌표계로 관찰하는 효과만 표현. 잘못된 형태의 궤도를 만들거나 행성 위치를 바꾸지 말 것.
- `prefers-reduced-motion`에서 정지된 그래프 제공. 키보드 접근, `aria-pressed` 또는 탭 역할 명확히.
- 실제 궤도 데이터로 구현하면 `/orbit/`의 계산 모듈과 모델 가정을 반드시 공유하고, 데모용 단순 곡선이라면 `개념도`로 표시.
- 기존 궤도 탐험기의 카메라·모드와 직접 연동할 수 있을 때만 deep link 사용; 동작을 확인하지 못한 쿼리 파라미터를 새로 가정하지 말 것.

### E. 결말 카피와 CTA
- 결말 핵심 문장: `우리가 멈춰 있다고 느끼는 것은, 움직이지 않기 때문이 아니라 거대한 움직임을 함께하고 있기 때문입니다.`
- 감정을 과도하게 설명하지 말고 곧바로 `/orbit/` CTA 배치.
- 모바일에서 CTA는 최소 44px 터치 영역.

### F. 출처 및 정확도
- 기사 최하단 출처 섹션은 기존 `/articles/earth-moon/`, `/articles/atomic-scale/` 구성과 동일한 출처 리스트/각주 컴포넌트 사용.
- 하단 설명: `대표 수치/근삿값, 기준좌표계, 시간 범위`를 간단히 밝힘.
- 본문에 실제 이차 출처를 'NASA 검증'이라고 뭉뚱그리지 말고 각 주장에 링크 연결.

### 절대 쓰지 말아야 할 설명
- `지구는 가속하지 않기 때문에 우리는 움직임을 못 느낀다` → **오류.** 궤도는 방향이 변하는 가속 운동.
- `지구가 너무 빨라서 몸이 둔감해진다` → **오류.** 속도 자체와 기준계 문제.
- `태양의 중력이 지표면에서 완전히 사라진다` → **오류.** 태양과 지구·관찰자가 거의 함께 운동하는 것.
- `지구를 포함한 행성들이 모두 태양 뒤에서 따라간다` → **오류.** 상호 위치와 진행방향은 변함.
- `지구·태양의 속도를 29.78 + 230 km/s로 더하면 지구의 은하 속도가 나온다` → **오류.** 속도는 방향이 있는 벡터이며 좌표계가 다름.
- `우리가 은하의 똑같은 공간으로 다시는 못 돌아간다` → 절대적 공간 기준을 전제한 표현이므로 금지. 필요 시 `은하 중심 기준으로 보면 한 해 뒤의 태양 위치도 달라져 있다`로 한정.
- `현재 행성의 실제 위치를 보여준다` → 기존 A2O `/orbit/`는 J2000부터 40년까지의 모델 시각, 실제 현시각 실측 표시 아님.

## 4. 프로젝트와 통합

1. 현재 저장소의 article 라우트, 콘텐츠 모델(Markdown/JSON/TS 등), 메타데이터, 탭/카테고리 구현을 탐색한 뒤 기존 패턴으로 새 글을 등록.
2. 추천 경로: `/articles/why-earth-feels-still/`. 기존 slug 규칙이 다르면 일관된 slug로 변경 가능. 내부 링크, canonical, OG/Twitter, `Article` JSON-LD 반영.
3. 분류는 `태양계와 우주` 또는 기존 `topic=cosmos`로 묶는다. `articles/` 목록과 홈의 최신·대표글에 추가하되, 기존 글 두 편을 삭제하거나 덮어쓰지 말 것.
4. 제목·설명, 줄바꿈, 출처 UI, 모바일 좌우 여백·최대 본문 너비는 기존 글의 디자인 토큰 재사용.
5. `/orbit/` CTA는 사이트 내부 이동; 움직임을 사전에 자동 실행하거나 사용자 동의 없이 설정을 변경하지 않음.
6. 장황한 수학 증명/천문 용어 사전은 본문 밖 '조금 더 알아보기' 아코디언 등으로 분리; 본문은 일반 독자에게 친숙해야 함.
7. 출판일을 과거 날짜로 소급하지 말 것. 새 글 발행 시점만 실제 기록.
8. 신규 이미지는 직접 만든 SVG 도식만 사용. 외부 사진·디자인 복제 없이 출처와 라이선스를 준수.
