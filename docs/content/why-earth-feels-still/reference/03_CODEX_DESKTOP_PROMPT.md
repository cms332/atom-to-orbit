# Codex Desktop에 그대로 전달할 작업 지시문

A2O(Atom to Orbit) 과학 아카이브에 새 과학 기사 **「태양은 움직이는데, 왜 우리는 제자리에 있다고 느낄까?」**를 추가해 줘.

우선 첨부된 다음 문서를 읽어:
- `01_ARTICLE_PUBLISH_READY.md`: 게시용 원고, 메타데이터, 참고 출처
- `02_EDITORIAL_DESIGN_AND_SCIENCE_GUIDE.md`: 화면 구성, 인터랙션, 과학 검증, 테스트 기준

개발 전 저장소의 `AGENTS.md`, 기존 `/articles/earth-moon/`, `/articles/atomic-scale/`, `/articles/` 목록, `/orbit/` 시뮬레이터와 현재 콘텐츠 구조를 먼저 살펴봐. **현재 디자인·콘텐츠 편집 방식·사이트 전체 룩을 보존**하고 기존 시스템에 자연스럽게 통합해.

구현 목표:
1. 기사 경로 `/articles/why-earth-feels-still/` (기존 라우트 명명 규칙과 충돌하지 않도록 조정 가능), `태양계와 우주` 분류, 목록/홈 연결, SEO 메타·canonical·Article 구조화데이터.
2. 원고의 정확한 핵심 설명 유지: 속도와 가속의 구분, 지구·우리의 태양 중력 아래 공통 궤도운동, 은하 중심 좌표계로 보면 달라지는 궤적. 독자가 이해하기 쉬운 글을 우선하고 긴 공식은 배제.
3. 기존 A2O Editorial Observatory 시각 언어로 ① 숫자 카드, ② `태양 기준/은하 기준` 비교 도식을 구현. 가능한 경우 간단한 SVG 인터랙션으로 기준계 토글하되, 실제 천문 모델이 아닌 개념도라면 분명히 고지. 기능과 사실적 정확성 확보가 먼저이며 무리한 3D 중복 구현 금지.
4. 본문 아래에서 기존 `/orbit/` 탐험기로 연결. 시뮬레이터가 현재 J2000~40년의 근사 모형이며 기본 은하 속도 표현은 1/20로 줄여 보여준다는 점을 필요한 위치에 설명.
5. 모든 수치는 NASA, ESA, NOAA, Smithsonian 1차 출처와 링크. 수치의 기준계와 근삿값 표시 누락 금지. 외부 사이트 코드·이미지 무단 복사 금지.
6. 모바일 390px, 데스크톱 1440px 반응형, 접근성(alt/figcaption/키보드/리듀스드 모션), 페이지 성능/SEO 유지.

**중요:** 현재는 로컬 구현 및 테스트까지만 진행. 실서버 배포, 외부 DNS 변경, 기존 코드의 대규모 리팩터링을 임의로 하지 마.

완료 후 브라우저에서 데스크톱/모바일 스크린샷을 확인하고 Svelte Check, ESLint, 빌드 및 Playwright 검증을 수행해. 수정 파일 목록과 품질·과학 검증 결과를 요약해 줘.
