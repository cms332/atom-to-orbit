# 움직이는 지구 기사 어린이 독해 개편

2026-10-23, 소유자가 전달한 개정안을 바탕으로 `/articles/why-earth-feels-still/`을 초등 3~6학년이 혼자 읽을 수 있는 방향으로 다듬는다. 제목·URL·카테고리·기존 발행 메타데이터 `2026-10-21`은 유지한다. 원자료의 기존 확인일을 바꾸지 않고 실제 개정일은 이 기록에 남긴다. 이번 요청은 로컬 구현과 검토이며 GitHub Push·공개 배포·서버/DNS 변경은 하지 않는다.

## 편집과 디자인

책상 앞의 일상 → 달리는 기차 → 중력 아래 함께 공전 → 태양계의 은하 운동 → 지구와 함께 지나온 시간의 순서로 네 절을 다시 쓴다. 자전·공전·중력·은하는 익숙한 말로 뜻을 설명한다. 마지막 문장은 ‘우리는 가만히 있는 것 같지만, 태어나던 순간부터 지금까지 지구와 함께 우주를 지나고 있습니다.’로 둔다.

기존 Taste Skill의 보존형 편집 기준을 이어 적용한다. Design Read는 초등학생을 위한 차분한 Editorial Observatory 과학 기사 개편이다. `DESIGN_VARIANCE: 5`, `MOTION_INTENSITY: 2`, `VISUAL_DENSITY: 4`. 기존 PC/모바일 열차·공전 그림의 캡처와 실제 구현을 먼저 확인했다. 본문과 설명의 이해 순서를 개선하며 브랜드·팔레트·폰트·기사 구조·탐험기 기능은 유지한다. 기존 두 SVG를 재사용하고 새 의존성·장식 그림·3D 엔진은 추가하지 않는다.

가속 운동·자유낙하·조석 효과·푸코 진자·코리올리 효과의 심화 설명은 첫 그림의 기존 접힌 메뉴를 ‘더 알아보기’로 바꾸어 모은다. 메뉴를 늘리지 않는다. 지구의 공전 방향이 계속 변한다는 사실, 중력의 뜻, 지구와 몸이 거의 함께 태양 중력을 받는다는 핵심은 쉬운 기본 본문에서도 읽힌다. 지표면에서 몸을 받치는 땅의 힘과 자전 효과가 남는 사실도 유지한다.

## 수치와 출처

기존 SI 속도와 출처 링크 10개를 그대로 보존한다. 주요 화면은 모두 시속으로 표시한다. 자전 약 1,670km/h, 공전 29.78km/s × 3,600 = 107,208km/h를 약 107,000km/h로 반올림, 은하 기준 230km/s = 828,000km/h다. 표시용 변환은 SI 원값에서 계산하며 원래 표시값·단위를 데이터와 하단 설명에 보존한다. 위도·궤도에 따라 달라지는 대표값임을 남기고 서로 다른 기준의 속도를 단순 합산하지 않는다.

10초간 2,300km, 지구 평균 지름 12,742km, 약 18%라는 계산은 유지한다. 본문에서는 5분의 1에 가까운 길이로 설명하고 정확한 식은 접힌 하단 ‘자료 및 출처’에 보관한다. 순간의 실측값으로 부르지 않는다.

NASA의 What Is Earth?·What Is an Orbit? 어린이 자료, What Is Microgravity? 5~8학년 자료를 직접 확인해 보완한다. 원래 10개 자료의 링크와 확인일은 보존하고 새 3개 NASA 자료에만 실제 확인일 2026-10-23을 기록한다. NASA Solar System Facts의 828,000km/h와 약 2억 3천만 년, Earth Fact Sheet의 평균 29.78km/s도 재확인했다. 제공된 ABC 글은 편집 참고 제안이며 새로운 과학적 수치를 의존하지 않으므로 별도 참고문헌으로 추가하지 않는다.

## 기존 체험의 유지

기차 도해는 ‘부드럽게 달릴 때’·‘갑자기 멈출 때’로 제목과 설명만 쉽게 쓴다. 실제 흔들림을 계측한 그림이 아닌 비유임은 접힌 안내에 남긴다.

기준 전환 직후의 설명은 태양을 따라가면 지구가 한 바퀴 도는 모습, 은하를 기준으로 보면 태양의 이동 때문에 길이 길게 이어지는 모습으로 설명한다. 재생/일시 정지·현재 위치에서 이어 재생·1년 슬라이더·Escape·포커스·스크린리더 상태 알림을 유지한다. 사용자가 지정한 재생 속도(일반 8초, 모션 감소 12초)와 그래픽 높이 1.7배도 변경하지 않는다.

과학 계산·상대 위치·투영·J2000 시각·태양 이동 1/20 비율을 바꾸지 않는다. 기본으로 보이는 짧은 그림 안내에 태양 이동을 보기 쉽게 1/20로 줄였다는 사실과 천체 그림 크기가 실제 비율이 아니라는 사실만 표시한다. 나머지 모형 설명은 계속 접어 둔다. 자동 재생은 없으며 JavaScript 없이 두 기준의 정적 그림도 읽을 수 있다.

## 검증

변환과 반올림을 단위 검사에 추가하고 기존 상대 위치·공전 계산 검사를 유지했다. 타입 검사 오류·경고 0개, 전체 단위 검사 62개, 전체 린트와 정적 빌드가 통과했다. 한글 폰트는 589음절을 포함하며 누락은 0개다. Naver 소유 확인 파일의 기존 해시도 유지했다.

PC/모바일 브라우저 검사 32개가 모두 통과했다(69.1초, 실패·불안정·건너뜀 0개). 시속 수치와 반올림, 네 목차, 쉬운 기본 본문과 접힌 심화, 원래 발행일·canonical·메타데이터, 각주와 13개 참고문헌, 기준 전환 직후의 설명과 상대 위치 보존을 확인했다. 기존 1.7배 그림 높이, 8초/12초 재생, 현재 위치 정지·이어 재생·슬라이더·Escape·완료 후 재시작·화면 이동 후 정리도 통과했다.

네 기사 공통 형식과 원자·지구와 달의 기존 체험도 같은 검사에서 정상이다. 390/320px·글자 200% 확대·키보드·모션 감소·Axe·JavaScript 없는 두 정적 기준 그림을 확인했다. 모바일은 Chromium 터치 에뮬레이션이며 물리 기기나 실제 초등학생 독해 실험을 수행했다는 뜻은 아니다.

실제 PC/모바일 시속 표시·기차 그림, PC 전체 글과 은하 기준 화면을 열어 확인했다. 결과는 `artifacts/motion-reading-level/results.json`, 새 본문·시속·기차 캡처는 같은 폴더, 두 기준과 재생 캡처는 `artifacts/motion-article/`와 `artifacts/motion-playback/`에 있다. 전체 형식 검사 후 무관한 파일의 내용이 같은 줄바꿈 변경만 복원한다. 로컬 4173 미리보기를 갱신하고 공개 Push·배포·서버/DNS 변경은 하지 않는다.
