# 기사 기준계 도식 재생 — 2026-10-21

소유자의 요청에 따라 ‘같은 운동, 다른 기준’ 도식의 설명과 그림 사이에 재생 버튼을 추가한다. 기존 Taste Skill의 보존형 편집 기준에 맞춰 청록색 테두리와 같은 SVG 좌표계의 삼각형·두 기둥으로 상태를 표시한다.

- 태양 기준과 은하 기준 모두 ‘▶ 재생하기’를 누르면 재생하고 ‘Ⅱ 일시 정지’를 누르면 현재 위치에서 멈춘다. 다시 누르면 같은 위치에서 이어간다.
- 초기 화면은 기존처럼 100%의 정적 도식이며 자동으로 시작하지 않는다. 끝까지 진행하면 멈추고 삼각형으로 돌아온다. 완료된 상태에서 재생하면 0%부터 다시 시작한다.
- 기준을 바꿔도 같은 시간과 재생 상태를 유지한다. 슬라이더 조작은 선택한 위치에서 정지시키며, 다음 재생은 그 위치에서 시작한다.
- 한 바퀴의 표시 시간은 로컬 최신 버전에서 기본 8초다. 모션 감소 설정에서는 직접 요청한 재생만 12초로 완만하게 진행한다. 기존 12초/18초보다 재생 속도를 각각 1.5배 높인 값이다. 과학 계산의 기준 시각·상대 위치·투영·1/20 표시 비율을 바꾸는 설정이 아니다. 이 속도 변경은 아직 배포하지 않았다.
- 키보드 Enter/Space로 작동하고 버튼의 Escape로 일시 정지한다. 버튼에는 선택 기준과 동작의 접근성 이름 및 연결된 그림/슬라이더를 명시한다. 수치 출력은 재생 중 반복 낭독하지 않으며 수동 슬라이더는 유지한다.
- 탭이 숨겨지거나 모션 선호가 바뀌면 현재 위치에서 정지한다. 컴포넌트가 제거될 때 프레임과 이벤트를 정리한다. JavaScript가 없으면 버튼은 비활성 상태이고 기존 두 정적 도식은 읽을 수 있다.
