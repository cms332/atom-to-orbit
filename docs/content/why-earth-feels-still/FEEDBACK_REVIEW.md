## 원자료

- [NASA Earth Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html): 평균 공전 속도 및 체적 평균 반지름.
- [NASA Reference Systems](https://science.nasa.gov/learn/basics-of-space-flight/chapter2-1/): Revolution of Earth 절의 공전 속도 범위.
- [NASA Solar System Facts](https://science.nasa.gov/solar-system/solar-system-facts/): 은하 중심 기준 대표 속도.

## 검증과 증거

기존 과학 계산 단위 검사에 SI 이동거리와 평균 지름 비율 확인을 추가한다. 기사 브라우저 검사에서는 두 기준의 강조 문구·범례, 안내와 도식의 표시 순서, 시간과 상대 위치 유지, 키보드·접근성·모션 감소, 320px 및 200% 글자 확대, JavaScript 없는 정적 도해를 확인한다. 폰트는 기존 생성 도구로 재구성하며 HTML 프리로드와 CSS를 같은 해시로 맞춘다.

이전 공개 도식은 `artifacts/motion-feedback/before-desktop-galactic.png`, `before-mobile-galactic.png`에 보존했다.

- 로컬 타입 검사: 오류·경고 0개. 린트·정적 빌드·단위 테스트 49개 통과.
- 기사 브라우저 검사: PC/모바일 8개 통과, 실패·불안정 0개 (23.6초). 초기 검사에서는 HTML output도 status 역할을 갖는 점 때문에 검사 선택자가 모호했다. 상태 문단으로 정확히 한정한 뒤 전체 기사 검사를 통과했다.
- 실제 `desktop-solar.png`, `mobile-galactic.png`를 열어 안내가 버튼 아래에서 바로 읽히며 도식·범례·출처가 겹치지 않는 것을 확인했다. 모바일은 Chromium 터치 에뮬레이션이며 물리 기기 검증이 아니다.
- 최종 로컬 보고서는 `artifacts/motion-feedback/local-results.json`; 수정 후 도식 캡처는 같은 폴더의 `after-*`에 보존한다.
- 폰트 생성기의 기본 권한에서는 기존 fontTools 폴더 읽기가 제한되어 승인된 권한으로 재실행했다. 생성 직후 HTML/CSS 형식을 맞춘 뒤 린트가 통과했다. 폰트 버전은 `e641478ceb02`, 125,708바이트이며 프리로드와 CSS 주소가 일치한다.
