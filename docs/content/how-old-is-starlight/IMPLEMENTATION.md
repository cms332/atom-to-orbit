# 별빛의 나이 — 제작·검증 기록

2026-10-28: 소유자가 제공한 원고·구현 가이드와 새 기사 공개 배포 요청을 기준으로 제작합니다.

## 독자와 흐름

- 초등학생이 혼자 읽을 수 있는 짧은 문장. 빛의 속도 → 반사된 달빛 → 햇살 → 어린 시절을 연결하는 시리우스 → 안드로메다은하 순서입니다.
- 제목과 경로: 「우리가 보는 별빛은 얼마나 오래전의 빛일까?」, `/articles/how-old-is-starlight/`.
- 기존 Editorial Observatory 디자인을 보존합니다. 본문은 종이색, 체험만 짙은 청록색입니다. 사진·새 3D 엔진·외부 런타임 API를 추가하지 않습니다.
- 작성일·독서시간은 본문에 표시하지 않습니다. 출처는 하단 한 곳에 접고 작은 번호 링크로 연결합니다. 상세 계산은 체험의 접힌 안내에 둡니다.

## 검증한 수치와 표현

NIST의 정확한 광속 299,792,458m/s와 JPL의 율리우스년 365.25일, 1AU 149,597,870,700m를 사용합니다. 1광년은 9,460,730,472,580,800m로 계산합니다.

| ----------------- | -------------- | ----------- | ---------------------------------------------------- |
| 달                | 384,400,000m   | 약 1.3초    | 달에서 반사된 이후 지구까지. 태양→달 구간 제외       |
| 태양              | 1AU            | 약 8분 20초 | 표면 부근→지구. 중심에서 표면까지의 에너지 이동 제외 |
| 프록시마 센타우리 | 4.24광년       | 약 4.2년    | 태양을 제외한 가장 가까운 별, 맨눈으로 보이지 않음   |
| 시리우스          | 8.6광년        | 약 8.6년    | 열 살 어린이의 약 한 살 시절과 연결하는 예시         |
| 안드로메다은하    | 250만 광년     | 약 250만 년 | 별 하나가 아니라 은하                                |

태양의 계산값은 약 499.005초입니다. 계기는 초 단위로 반올림해 8분 19초, 설명용 대표값은 약 8분 20초이며 차이를 접힌 계산 안내에 설명합니다. 표시용 문자열이 계산에 들어가지 않습니다. 실시간 천체 위치, 과거 날짜, 별의 현재 생존 여부를 추정하지 않습니다. 광년은 거리이며 망원경은 원하는 과거를 재생하는 기계가 아닙니다.

원자료 URL과 항목별 근거는 `src/lib/data/starlight.ts`의 11개 출처에 보관합니다. NIST·NASA·JPL 본문을 확인했으며 프록시마 4.24광년은 파리천문대 원자료의 검색 인덱스에서도 확인했습니다. 해당 파리천문대 본문 조회는 도구 시간 초과가 발생했습니다. NASA의 별도 원자료로 맨눈 관측 불가와 가까운 별이라는 설명을 교차 확인했습니다.

## 체험과 접근성

- 기본 달·진행률 0·정지. 모든 천체가 화면에서 10초 동안 같은 길을 선형으로 이동하며, 실제 거리·시간 비례가 아님을 항상 표시합니다.
- 실제 이동 시간은 거리/광속에서 구합니다. 천체 선택은 재생을 취소하고 시작점으로 돌립니다. 일시정지·이어보기·처음부터·슬라이더를 제공합니다.
- 광원은 사라지지 않습니다. 움직이는 점은 빛의 전달을 설명하는 표시이며 실제 광자 관측이나 한 번의 섬광이 아닙니다.
- 동작 줄이기에서는 ‘애니메이션 켜고 따라가기’로 이번 체험의 움직임을 직접 선택합니다. 움직임 없이 살펴보려면 기존 슬라이더를 사용하며 별도 도착 버튼은 없습니다. 재생 버튼이 설명 없이 도착으로 건너뛰지 않습니다. 자동 재생하지 않으며, 탭 숨김·천체 변경·기기 설정 변경·페이지 이탈 시 애니메이션을 중지합니다.
- 화면 낭독 안내는 선택·도착 등의 사건에만 갱신하며 프레임별 시간은 읽지 않습니다. 자바스크립트 없이 본문·동일 데이터 5행 비교표·접힌 계산/출처·정답·관련 링크를 읽을 수 있습니다.
- 개인정보 입력이나 새 추적 이벤트를 추가하지 않습니다.

## 어린이 독해와 재생 동작 보완 — 2026-10-28

- 소유자가 제공한 교정안과 실제 게시본을 대조했다. ‘빛이 눈에 도착해야 보인다’는 연결을 추가하고 반사·광년을 생활 언어로 먼저 설명한다. 시리우스는 열 번째 생일이라는 한 장면으로 한정하고, 8.6년을 약 8년 7개월로 풀어 쓴다. 안드로메다의 지금 모습과 250만 년 전 모습을 구분하며 결말의 반복을 줄인다.
- 본문과 큰 시간 표시는 태양의 대표값 약 8분 20초로 통일한다. SI 거리와 계산은 보존하며, 초 단위로 반올림한 8분 19초와 이동 위치별 계산 시계는 기본으로 닫힌 상세 설명 안에 둔다. 달의 출발은 반사된 빛임을 밝히고 도착 문장에는 대상과 시간을 함께 적는다.
- 공개 페이지의 재생 즉시 도착 증상을 `prefers-reduced-motion: reduce` 조건에서 재현했다. 일반 설정에서는 약 3초 동안 이동하지만 기존 동작 줄이기 분기가 즉시 진행률을 1로 만들었다. 기기 설정 자체를 바꾸지 않고 명시적 애니메이션 선택과 정지 화면 선택을 나누었다. 선택은 현재 체험 안에서만 유지되며 저장하지 않는다.
- 이번 보완 요청은 로컬 수정과 확인 범위다. 이전 신규 기사 배포 승인을 이어 적용하지 않으며, 별도 배포 요청 전에는 공개 Push나 배포를 진행하지 않는다. 검증 결과는 진행 기록에 남긴다.

## 빛을 따라가는 경과 시간 — 2026-10-28

- 소유자가 3초 재생 중 실제 빛의 이동 시간을 가늠할 수 있도록 요청했다. 빛의 점 아래에 ‘경과 시간’을 표시하고, 위치와 동일한 진행률을 기존 SI 거리/광속 계산에 적용한다. 시리우스 중간은 약 4.3년, 안드로메다 중간은 약 125만 년이다. 재생·일시정지·이어보기·슬라이더·초기화·천체 변경·정지 도착 화면 모두 같은 상태를 사용한다.
- 움직이는 표시는 작은 화면에서도 글자가 작아지지 않는 HTML 글자이며, 양 끝에서는 도판 안쪽으로 위치를 제한한다. 출발/지구 표시는 선 위쪽으로 옮겨 경과 시간과 겹치지 않게 한다. 화면 낭독기에서는 타이머로 탐색할 수 있지만 프레임별 자동 낭독은 하지 않는다. 슬라이더의 접근성 값에도 같은 시간을 제공한다.
- 실제 값은 변경하지 않는다. 태양의 움직이는 경과 시간만 10초 단위로 반올림해 중간 약 4분 10초, 도착 약 8분 20초로 표시한다. 499.005초와 초 단위로 반올림한 8분 19초는 상세 계산에 보존한다. 3초는 여전히 공통 시연 길이이며 실제 이동 비율을 천체 사이에서 비교하는 화면이 아님을 안내한다.
- 이번 추가 요청도 로컬 확인 범위이며 공개 Push·배포는 하지 않는다.

## 경과 시간 숫자 깜빡임 보완 — 2026-10-28

- 소유자가 ‘약 xx.x만 년’에서 숫자가 잠깐 사라지는 듯한 깜빡임을 보고했다. 수정 전 3초 재생을 계측했을 때 180개 이동 프레임에서 숫자가 비는 DOM 문자열은 검출되지 않았으나, 약 181회의 문자열 갱신과 약 85~122px의 글자 폭 변화를 확인했다. 이 계측만으로 사용자의 기기에서 보인 픽셀 누락까지 재현했다고 주장하지 않는다.
- 빛과 꼬리의 위치는 매 프레임 갱신하되 숫자는 약 100ms 간격으로 갱신한다. 일시정지·사용자 조작·기기 설정 변경·탭 숨김·도착에서는 즉시 현재 값과 맞춘다. 숫자·‘약’·단위를 별도 DOM 요소에 두고 숫자 영역의 폭을 고정한다.
- 소수 한 자리와 대상별 단위를 출발부터 도착까지 유지한다. 안드로메다는 `약 0.0만 년`에서 `약 250.0만 년`으로 진행하며 정수도 `80.0`처럼 표시한다. 태양의 초는 `00`처럼 두 자리를 유지한다. 원래 SI 값과 3초 시연 길이는 그대로다.
