# 궤도 탐험 간소화 재설계 — 2026-10-20

> 후속 요청으로 재생 버튼을 없애고 상시 움직임·스토리 자동 진행·1.3배 속도·수금지화 시작 구도를 적용했습니다. 현재 동작과 검증은 [상시 움직임·자동 이야기](ORBIT_CONTINUOUS_MOTION.md)를 우선합니다. 아래 4버튼·감소된 모션 정지·14초 이야기 기록은 이 후속 변경 이전 상태입니다.

## 소유자의 지적과 적용 범위

별도 3D 시작 버튼, Clockwork 중심의 첫 화면, 작동을 신뢰하기 어려운 시점 변경, 상시 노출된 많은 조작부를 교체합니다. 기존 브랜드·메뉴 순서·케플러 계산·선형 AU 거리·제거된 페이지 정책은 유지합니다. 공개 배포는 하지 않습니다.

Taste Skill의 보존형 읽기를 이어 적용합니다. 이번 인터랙티브 장면은 사용자가 명시적으로 요청한 3D 체험입니다. 편집 화면의 낮은 모션 규칙으로 체험 자체를 막지 않으며, 감소된 모션 환경에서는 자동 재생과 카메라 보간을 끕니다. 시각 밀도는 4에서 2로 낮추고, 장면을 첫 화면 전체로 확장합니다.

## 참고 자료와 선택

- [The Helix](https://mathew-harvey.github.io/TheSolarSystem/)의 실행 화면과 도크, 스토리·시점·속도 UI를 다시 관찰했습니다. 장면이 먼저 열리고 조작부가 아래에 모이는 구성을 참고합니다. 프로그램과 셰이더를 복제하지 않습니다. A2O 기본 도크는 스토리 / 태양계 / 은하 궤적 / 재생·정지 네 버튼으로 줄였습니다.
- [pcwilliams/solarsystem-web](https://github.com/pcwilliams/solarsystem-web)의 README, MIT 라이선스와 THIRDPARTY 자료를 확인했습니다. JPL 모델, 행성 선택 시 카메라 이동, 표면 지도·고리를 적용한 천체 식별 경험을 참고했습니다. 코드나 저장소의 텍스처 파일은 가져오지 않았습니다.
- [DotNetTitan/HeliocentricSpiralMotion](https://github.com/DotNetTitan/HeliocentricSpiralMotion)의 기능·GPL-3.0 고지를 확인했습니다. 태양 이동과 기울어진 공전면을 함께 보여주는 경험을 참고하며, GPL 코드와 해당 저장소의 텍스처는 사용하지 않습니다.
- [SoumyaEXE/3d-Solar-System-ThreeJS](https://github.com/SoumyaEXE/3d-Solar-System-ThreeJS)의 README와 표면을 구분한 3D 모델·마우스 탐색 구성을 확인했습니다. 코드·자산을 가져오지 않았습니다.

표면 지도의 권리는 다른 저장소의 설명에만 의존하지 않고 [Solar System Scope 공식 배포 페이지](https://www.solarsystemscope.com/textures/)에서 CC BY 4.0 조건을 확인했습니다. 공식 JPEG 10종을 로컬 1024×512 WebP로 축소·변환했습니다. 저작자·원본 URL·라이선스·변경 내역은 `/licenses/orbit-textures.txt`와 사용자 화면의 접힌 출처 안에 남깁니다. 텍스처 합계는 526,892바이트입니다. 미관측 지역 보완·색 보정도 설명합니다.

## 변경한 경험

- 경로에 들어오면 엔진을 자동 로드합니다. 정상 상태에 진입 버튼이 없습니다. 오류 때만 다시 시도를 제공합니다.
- 기본은 움직이는 은하 궤적, 1년=10초, 태양 이동 성분 1/20입니다. 감소된 모션은 자동 로드하되 정지합니다.
- 화면 하단에는 네 개의 핵심 조작만 남깁니다. 시간·표시·천체 선택은 우측 설정 한곳에, 과학 모델·표·출처는 장면 아래 닫힌 상세 설명에 둡니다.
- 태양계와 은하 궤적 전환은 새 좌표계·속도를 카메라 함수에 명시적으로 전달합니다. 재생·탐색 시각을 유지하고 1.4초 보간으로 실제 위치와 목표점을 바꿉니다. 초기 진입과 감소된 모션에서는 보간하지 않습니다.
- 은하 카메라가 궤적 축을 내려다보지 않고 옆에서 보도록 수정했습니다. 모바일은 카메라 위쪽 축을 생성 시점에 설정해 긴 궤적을 세로로 보여줍니다. OrbitControls가 생성 때 up축을 저장하므로 생성 뒤 임의 변경하지 않습니다.
- 행성 또는 이름을 누르면 가까이 이동해 해당 표면을 관찰합니다. 근접 화면에서는 다른 확대 표식과 궤적을 숨겨 행성 앞을 가리는 문제를 없앱니다. 설정의 가까이 보기 선택은 모든 행성에 대한 키보드 대안입니다.
- 지구 구름·대기 가장자리, 토성 절차적 고리, 태양 표면 지도와 뒤쪽 후광, 장식용 별 배경을 추가합니다. 새 표면·조명·고리·별·자전 표현은 관측 예측이 아닙니다.
- 궤적은 현재로 갈수록 선명해지고 1.35px 폭으로 읽힙니다. 매 프레임 선 객체를 생성하지 않으며 GPU 버퍼를 재사용합니다. 30fps 상한, 궤적 12Hz, 화면 밖/탭 비활성 중지, DPR 상한과 경로 이탈 시 정리를 유지합니다.
- 스토리는 지구 근접에서 시작해 공전·태양의 이동·기울어진 궤적·실제 속도 비교로 이어집니다. 재생 중 14초마다 진행하고 이전/다음으로 직접 이동할 수 있습니다. 드래그나 직접 보기 선택은 이야기를 종료합니다.

## 검증

- 최종 `bun run check`: 오류 0 / 경고 0. `bun run lint` 통과. 계산 모델 35개 단위 테스트 통과. `bun run build` 정적 빌드 통과.
- 최종 프로덕션 빌드에서 Chromium 데스크톱·모바일 **14건 모두 통과**, flaky 0. 새 궤도 경험 10건과 공용 메뉴·내부 링크 4건입니다. 전체 기존 66건을 이번에 다시 돌렸다는 의미는 아닙니다. 원본 결과: `artifacts/orbit-revision/final-results.json`.
- 자동 진입과 재방문 자동 로드, 닫힌 설정과 네 버튼 도크, 반복 좌표계 전환의 실제 카메라 변경·모델 시간 보존, 실제 속도 비교, 지구·토성 근접 보기, 표시 옵션·탐색·배속·키보드 조작, 여섯 스토리 카메라·자동 진행·드래그 중단, 감소된 모션, 컨텍스트 상실·WebGL 불가·JavaScript 비활성 대체를 검증했습니다.
- 320–1440px에서 수평 넘침과 도크 경계를 확인했고 844×390 가로 화면에서 도크가 화면 안에 남는 것을 검증했습니다. 200% 글자 확대에서는 설정 내부 세로 스크롤과 버튼 줄바꿈으로 콘텐츠를 유지합니다. Axe 자동 접근성 검사 위반 0. 네트워크·페이지·3D 셰이더 오류가 없는 정상 경로를 확인했습니다.
- 초기 실행의 no-JS 두 건은 Playwright 텍스트 검색기가 `noscript` 내부를 건너뛰는 선택자 문제로 실패했습니다. 실제 안내는 화면에 표시됨을 DOM·캡처로 확인한 뒤 `noscript p`를 직접 검사하도록 바꿨습니다. 최종 14건은 수정된 선택자와 최종 빌드에서 한 번에 통과했습니다.
- 실제 캡처: `artifacts/orbit-revision/desktop-entry.png`, `mobile-entry.png`, `desktop/mobile-solar.png`, `desktop/mobile-earth.png`, `desktop/mobile-saturn.png`, `desktop/mobile-story-3.png`, `desktop/mobile-story-5.png`, `desktop/mobile-large-text.png`. 파일명의 `desktop/mobile-`은 각각 두 파일을 뜻합니다. 초기 숫자 이름의 캡처와 `no-js-before.png`는 조정 과정 자료입니다.
- 자산 실측: 렌더러 청크 592,701바이트 / gzip 150,241바이트. 텍스처 10개 합계 526,892바이트. `artifacts/orbit-revision/asset-audit.json`에 원본 파일별 값을 저장했습니다. 3D 엔진은 해당 경로의 마운트 때 자동 로드하며 첫 버전의 ‘시작 전 로드하지 않음’ 검증은 현재 요구와 다릅니다.

한계: 모바일은 Chromium 에뮬레이션으로 확인했습니다. 실제 iOS/Android 기기의 FPS·발열·배터리 소모나 브라우저별 GPU 호환성을 측정하지 않았습니다. 정밀 천체력·실제 크기 비례·정확한 자전 방향·별자리 지도는 이 모델의 범위가 아니며 사용자 화면에도 구분합니다. 공개 배포·DNS 변경은 하지 않았습니다.
