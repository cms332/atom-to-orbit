## 디자인 계획과 명세 대조

사용 목적은 한국어 독자가 크기·거리 관계를 이해하고 출처를 확인하는 것입니다. 기억에 남는 중심은 실제 작동하는 로그 탐험기로 두고, 편집 화면의 나머지 요소는 읽기를 돕도록 정리합니다.

| 역할      | 고정한 기준                                                      |
| --------- | ---------------------------------------------------------------- |
| 바탕      | 종이색 `#F7F8F4`, 데이터 표면 `#FFFFFF`                          |
| 글자      | 잉크 `#162A33`, 보조 글자 `#586B74`                              |
| 상호작용  | 청록 `#286875`                                                   |
| 측정 강조 | 구리색 `#D6A16A`; 기존 짙은 청록 계측 패널 유지                  |
| 한글      | 자체 호스팅 A2O Sans Subset, 제목·본문의 크기와 굵기로 위계 형성 |
| 수치      | 실제 단위·지수·측정값에 시스템 monospace 사용                    |
| 움직임    | 짧은 입력 피드백, reduced-motion 대응; 자동 장식 동작 추가 없음  |

구성은 다음처럼 읽기와 조작의 역할을 구분합니다.

```text
홈       제목·설명·탐험 진입 | 실제 로그 탐험기
         눈금 안내 → 주제 탐색 → 거리 설명 → 실제 원고 → 방법
목록     페이지 제목 → 주제 필터 → 결과 안내 → h2 기사 제목
본문     분류·제목 → 요약·목차 → 과학 도식 → 설명 → 출처
방법     측정 기준 → 계산·정의 → 원자료 → 수정 원칙
```

마스터 명세가 이미 팔레트·글꼴·정적 구조·과학 시각화를 정했으므로 이 기준을 유지했습니다. 일반적인 랜딩 페이지 카드나 새 회사 색상으로 대체하지 않았습니다. 기사·출처·404처럼 읽는 목적이 강한 화면은 제목과 실제 안내를 먼저 보여주도록 계획을 대조한 뒤 수정했습니다.

## 이번 코드 변경

- **공통 기사 구성:** `ArticleCard.svelte`에 제목 단계 선택을 추가했습니다. 홈은 섹션 h2 아래 h3, 기사 목록은 페이지 h1 아래 h2로 연결됩니다. 링크의 접근성 이름은 기사 제목, 설명은 요약으로 구분했습니다.
- **분류와 목차:** `EXPLAINED`, `IN THIS STORY`, `KEEP EXPLORING` 등 중복 영문 문구를 정리했습니다. 실제 기사 분류와 한국어 목차 안내는 유지합니다.
- **페이지 제목:** 탐험·목록·방법·소개·변경 기록에서 제목 위의 장식용 영문 라벨을 제거했습니다. 방법 페이지의 개념 제목에서 불필요한 번호를 제거했습니다.
- **홈:** 전체 제목을 동일한 문자 스타일로 표시하고, 기존 과학 탐험기 중심 구성을 유지했습니다.
- **푸터·오류:** 푸터의 중복 영문 장식을 줄이고 링크의 키보드·마우스 강조를 맞췄습니다. 오류 화면은 실제 상태 번호와 복귀 안내를 사용합니다.
- **모바일·테스트 준비:** 목차의 축소 가능한 그리드를 적용했습니다. 기존 Playwright 시나리오에 기사 목록의 제목 단계와 짧은 링크 이름 확인을 추가하고, 좁은 너비 320/375/414px 및 주요 페이지 캡처 대상을 늘렸습니다.

과학 측정값·단위 환산·로그 좌표·출처·기사 본문·페이지 경로는 변경하지 않았습니다. 선택 메뉴 아웃라인 제거 요청과 기존 네이티브 입력, 키보드 탐색, 동작 줄이기 설정도 유지합니다. 새 런타임 의존성은 없습니다.

차단 사유는 `Automatic approval review failed: Selected model is at capacity`입니다. 안전성 거절이 아니라 승인 검토 자체의 실패로 보고됐습니다. 같은 승인을 우회하는 경로를 사용하지 않았습니다.

따라서 **이번 최종 코드의 타입·린트·테스트·빌드·시각 검증은 미완료**입니다. 시작 시점의 타입 검사 통과나 과거 v0.1.2 검사를 최종 결과로 대신하지 않습니다. 테스트의 `artifacts/anthropic-after/`는 다음 실행의 출력 경로로 설정한 것이며, 이번에 새 스크린샷이 생성됐다는 뜻이 아닙니다.

검토 환경 복구 후 포맷·필수 검사·정적 빌드를 먼저 실행하고, 그 빌드에서 데스크톱 1440px·모바일 390px 및 추가 너비·200% 글자 확대·접근성을 확인해야 합니다. 시각 검증 전까지 전방위 개선이 완성됐다고 판정하지 않습니다. 공개 배포·DNS 변경·원격 push는 하지 않았습니다.
