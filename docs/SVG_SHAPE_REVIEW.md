## 검증 자료

### 탁구공 무광 오프화이트 — 후속 요청

사용자가 제공한 기존 화면의 밝은 반사선을 제거했다. 청록색 바탕을 따뜻한 오프화이트(`#EDEDE6`)로 바꾸고, 넓고 낮은 대비의 확산 명암만 넣었다. 순백색의 반사점, 광택 호, 외곽 글로우는 없다. 기본 도형과 확대 시 대체 표면의 색상을 함께 조정했다. 측정 지름 40mm와 100단위 원형은 그대로다. 390px·1440px 실제 탐험기 캡처: `artifacts/matte-table-tennis-ball/`.

이어 사용자가 오른쪽 아래에 배경색 음영을 요청했다. 왼쪽 위 광원에 맞춰 32%·28% 중심의 넓은 방사형 음영을 원반 내부에 추가했다. 배경색 `#102832`의 불투명도를 밝은 영역 0에서 반대쪽 가장자리 최대 34%까지 점차 높여 곡면을 표현한다. 기존 무광 오프화이트 바탕과 반사선 없는 표현은 유지한다. 바닥에 드리우는 그림자나 원반 밖 효과는 추가하지 않았다. 실제 데스크톱·모바일 화면: `artifacts/table-tennis-shading/`.

### 태양 배경 글로우 — 후속 요청

태양 주변을 특별하게 표현해 달라는 요청에 따라 장식용 글로우를 추가했다. 이어 전면을 선명하게 해 달라는 요청을 반영해, 글로우는 원반과 별도의 뒤쪽 형제 레이어에 둔다. 두 방사형 그라디언트 모두 측정 원반 내부는 완전히 투명하고 바깥에서만 빛이 퍼진다. 원반에는 얇은 내부 경계선을 더해 표면·흑점과 가장자리를 또렷하게 유지한다. 광륜 반경은 장식 값이며 태양의 물리적 지름이나 실제 코로나 범위가 아니다. 측정 SVG는 100×100, 외부 빛은 클릭을 받지 않는 별도 레이어다. 움직이는 필터나 점멸 효과는 사용하지 않았다.

`tests/sun-glow.spec.ts`는 뒤쪽 DOM 순서, 원반 내부의 글로우 픽셀 0개, 원반 밖의 빛 존재, 측정 폭 불변, 키보드 양 끝 이동을 검사한다. 실제 패널 캡처는 `artifacts/sun-glow/`에 저장한다.

- 수정 전·후 전체 27개: `artifacts/glyph-review/before/`, `artifacts/glyph-review/after/`. `scripts/audit-scale-glyphs.mjs`로 재생성할 수 있다.
- 데스크톱·모바일 실제 탐험기: `artifacts/glyph-review/desktop-*.png`, `mobile-*.png`.
- 회귀 테스트는 27개 SVG의 고유 ID·자체 참조, 태양을 포함한 8개 수정 원반의 불투명한 원형 경계와 지구의 실제 육지/바다 검사 지점을 확인한다. 기존 테스트는 물리적 크기 비율, 토성 고리, 태양 종점, 재생, 반응형·접근성을 함께 확인한다.
- 실제 실행 결과는 이번 작업의 완료 기록과 `artifacts/glyph-review/playwright-results.json`에 기록한다.
