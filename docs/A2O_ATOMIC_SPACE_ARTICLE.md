# 원자 속 거리와 물질의 단단함

## 범위와 편집 방향

2026-10-23 소유자가 전달한 `A2O_Atomic_Space_Content_Pack.zip`의 세 문서를 검토했다. 이번 요청은 새 과학 이야기를 구현해 **로컬에서 검토**하는 단계다. 공개 배포·Push·운영 서버와 DNS 변경은 포함하지 않는다.

주소는 `/articles/empty-space-in-atoms/`, 제목은 **원자는 거의 빈 공간인데, 왜 책상은 단단할까?**다. 기존 원자 기사가 크기의 정의와 단위를 다룬다면, 새 글은 핵과 전자 분포의 거리 차이에서 물질의 단단함으로 이어진다. 친숙한 책상 → 약 315m의 길이 비교 → 전자의 확률 분포 → 빈 공간 비유의 한계 → 전자기적 상호작용과 파울리 원리 → 손바닥의 감각 순서다.

기존 기사와 같은 본문 폭·목차·제목 체계·접힌 도해 설명·하단 한곳의 접힌 참고문헌을 사용한다. 작성일·읽기 소요시간은 표시하지 않는다. 아직 공개되지 않은 새 글에는 `datePublished`를 만들어 넣지 않으며, 기존 세 기사의 실제 날짜 메타데이터는 유지한다. 이후 공개 승인 시 실제 게시 날짜를 기록해야 한다.

Taste 적용 범위는 Editorial Observatory의 보존 편집이다. **DESIGN_VARIANCE=5, MOTION_INTENSITY=2, VISUAL_DENSITY=4**. 따뜻한 종이와 잉크 본문, 기존 midnight-teal 도구색과 구리색 과학 표지를 사용한다. 과학 도해에는 직접 제작한 SVG만 사용하며 사진·3D 엔진·새 디자인 라이브러리는 추가하지 않는다. 자동 재생 없이 독자가 거리와 확률을 직접 선택한다. 네 기사가 된 홈페이지 목록은 빈 칸 없는 두 열 구성으로 맞춘다.

## 검증한 과학과 계산

- NIST 2022 CODATA 전체 상수표에서 `a₀=5.29177210544e-11 m`, 양성자 전하 RMS 반지름 `rₚ=8.4075e-16 m`를 확인했다. 원문의 CGI 링크는 조회 도구에서 잘못 정규화되어 안정적인 NIST 전체 표 링크로 대체했다.
- 비교는 수소-1 원자의 바닥상태(1s), 고정된 핵을 가정한 비상대론적 모형이다. `2rₚ`를 1cm로 키운 배율을 `a₀`에 동일하게 적용한다. 반지름과 지름을 혼용하지 않는다. 약 315m는 중심부터의 거리, 약 630m는 양쪽 `2a₀` 길이다.
- RMS 반지름은 양성자 전하 분포의 크기 척도다. 고체 구슬의 표면이나 확정된 핵 경계가 아니다. `2a₀`도 모든 원자의 지름이나 수소의 고정 경계가 아니다.
- OpenStax University Physics 8.1의 1s 파동함수와 구껍질 확률식을 확인했다. `x=r/a₀`일 때 중심 대비 공간 확률밀도는 `exp(-2x)`, 단위 x당 거리별 확률밀도는 `4x²exp(-2x)`다. 전자는 행성형 고정 궤도를 돌지 않는다.
- 거리별 분포의 최댓값 `x=1`은 평균 거리가 아니다. 공간 밀도는 중심이 가장 높으며, 바깥 구껍질의 부피 요소 때문에 거리별 분포와 최대 위치가 다르다.
- 구껍질 구간 확률은 `F(x)=1-exp(-2x)(1+2x+2x²)`의 차로 계산한다. 점 하나의 발견 확률로 표시하지 않는다. 범위 밖의 확률도 이어진다.
- 실제 수소의 유한한 핵 질량은 이 근사 길이 척도를 약 0.05% 바꾼다. 약 315m라는 반올림에는 영향을 주지 않으며 고정핵 근사는 도해 설명과 참고문헌에서 명시한다.
- OpenStax College Physics 30.9에서 완전한 양자 상태와 스핀의 구분을 확인했다. 파울리 원리를 전자구름의 공간적 겹침 금지나 별도의 고전적 반발력이라고 설명하지 않는다. 물질의 안정성에 관한 Lieb 논문은 공개 초록을 확인했으며 본문 전체를 읽었다고 주장하지 않는다.
- 외부 참고 그림·PPT·이미지는 복제하지 않았다. 정확한 빈 공간 백분율, 전자의 크기, 고정 궤도와 임의의 출판 날짜는 추가하지 않는다.

## 도해와 연결

**핵을 1cm로 키우면:** 처음에는 400m의 가로 범위 안에서 핵 중심과 약 315m 눈금을 보여준다. 버튼·슬라이더로 4cm 범위까지 확대한다. 확대 제어는 로그 간격, 실제 그림의 가로 좌표는 선형이다. 핵이 화면의 한 픽셀보다 작을 때는 십자 위치 표시로 바꾸고 비례 그림이 아닌 위치 표지임을 명시한다. 전자 입자·행성 궤도는 그리지 않는다.

**같은 전자구름, 두 가지 질문:** 수소 1s 공간 확률밀도의 중심 단면과 거리별 확률밀도 그래프를 비교한다. 단면은 3D 투영이나 입자 궤적이 아니다. 같은 거리 슬라이더가 선택한 구껍질 단면, 그래프의 면적, 실제 pm와 모형 m의 길이, 구간 확률을 함께 갱신한다. 그래프는 무차원 거리 단위당 확률밀도로 축을 표시한다. 핵 위치 점은 크기 비례를 생략했다고 명시한다.

SSR에서 기본 도해·핵심 수치·본문·참고문헌을 읽을 수 있다. JavaScript가 없으면 작동할 수 없는 제어만 비활성화되며 native details와 링크는 동작한다. 작은 화면에서는 확률 도해 두 개가 세로로 쌓인다. 버튼·range 입력은 최소 44px의 조작 높이를 확보한다.

홈페이지·과학 이야기 필터·동적 기사 경로·sitemap은 기사 데이터와 연결했다. 기존 원자 기사와 새 글은 ‘다음 이야기’ 및 본문 탐험 연결로 오갈 수 있고, `/scale/?object=atom`으로 이어진다. 다른 기사 내용·궤도 탐험기·분석 추적·서버 설정은 바꾸지 않는다.

## 초등 고학년 읽기 수준으로 수정 — 2026-10-23

소유자는 첫 원고가 지나치게 학술적이라고 지적하고, 초등 5~6학년이 이해할 수 있는 원고를 제공했다. 최신 편집 기준을 이 요청으로 바꾼다. 본문은 짧은 문장과 구슬·축구장·전자를 찾는 지도로 설명한다. RMS·fm·보어 반지름·스핀·오비탈·비상대론적 모형 같은 정의와 계산식은 기본 본문·도해에서 읽도록 요구하지 않고, 기존의 접힌 설명과 하단 원자료에 보존한다. 파울리 원리는 이름과 쉬운 설명을 함께 제시한다.

주신 다섯 절 제목과 글 흐름, 일상적인 맺음말 및 탐험기 안내를 반영했다. 실제로 옮기는 대상을 잘못 암시하지 않도록 ‘전자구름을 움직여’는 ‘살펴볼 거리를 바꿔’로 표현했다. 과학 내용은 바꾸지 않고 작은 공간을 비교하는 질문과 같은 두께의 둥근 공간을 모아 보는 질문을 구분한다.

거리 도해에 1cm·약 315m·약 630m 세 행의 비교 표를 둔다. 확률 도해의 기본 좌표와 선택 결과는 낯선 a₀·pm 대신 동일한 1cm 구슬 모형의 m 단위로 표시한다. 곡선의 모양은 유지하면서 세로 높이를 최댓값으로 나누어 ‘높음/낮음’의 상대적인 발견 가능성으로 설명한다. 구간 확률은 기존의 정확한 적분 계산을 그대로 사용한다. 수치 환산·파동함수·기존 상수는 변경하지 않는다.

## 핵 확대 단계별 안내 보정 — 2026-10-23

핵의 반지름이 1px을 넘는 즉시 1cm 안내로 바뀌던 조건을 수정한다. 십자 표시만 보이는 단계, 작은 핵이 보이기 시작한 단계, 끝까지 확대한 1cm 구슬 모형의 세 상태를 그림과 동일한 조건으로 연결한다. 중간 단계는 ‘확대해 보니 핵이 서서히 눈에 보이기 시작하네요.’로 안내하며, 1cm 안내와 라벨은 마지막 단계에서만 표시한다.

화면 폭에 따라 확대 종점의 시야를 계산해, PC와 모바일 모두 핵의 표시 지름이 CSS 1cm(96/2.54px)가 되도록 한다. 따라서 기존의 고정 4cm 시야 종점은 사용하지 않는다. 브라우저 기준 길이이며 물리 기기의 실제 크기나 브라우저 확대율을 교정한 실측값은 아니라는 설명은 접힌 모형 안내에 둔다. 400m 전체 보기, 315m 비교 및 핵과 거리의 비율은 유지한다. 세 단계와 축소 복귀·화면 폭 변경 검증을 기존 브라우저 검사에 추가하며, 로컬 결과 확인 후 기록한다. 공개 Push나 배포는 하지 않는다.
