# 홈 탐험기 높이 안정화

작업·검증일: 2026-10-19 (KST).

원자와 다른 대상으로 슬라이더를 옮기면 홈의 SVG 패널 높이가 달라지는 현상을 수정했습니다. 수정 전 Playwright에서 원자 → 탁구공 전환 시 데스크톱 1440px에서는 3.90625px, 모바일 390px에서는 107.375px의 높이 차이를 재현했습니다.

SVG 영역은 이미 고정 높이였습니다. 원자의 긴 이름과 수치가 차지하는 줄 수, 좁은 화면의 이름·수치 행 배치가 높이를 바꾸는 원인이었습니다.

`ScaleExplorer.svelte`의 홈 미리보기에서 원자 이름·수치와 같은 공간을 항상 확보하도록 CSS Grid의 겹친 영역을 사용합니다. 예약 요소는 `visibility: hidden`과 `aria-hidden`으로 화면·접근성 트리에서 제외합니다. 같은 Svelte 표시 스니펫을 공유하므로 현재 글꼴 크기와 화면 너비에 맞춰 공간을 계산하며 고정 픽셀 높이나 JavaScript 측정에 의존하지 않습니다. 실제 표시와 슬라이더 조작, 과학 데이터·출처는 유지했습니다.
