# 자동 재생과 구체적인 출발점 — v0.1.9

구현일: 2026-10-19 (KST). 소유자의 세 가지 브라우저 코멘트를 반영했습니다.

후속 수정: 같은 날짜에 실제 브라우저의 동작 줄이기 설정에서 대상별 점프가 재현되어, 직접 시작한 재생은 이 설정에서도 1.5배 느린 연속 이동을 사용하도록 바꿨습니다. 최신 검증은 [연속 재생 수정 기록](CONTINUOUS_PLAYBACK.md)을 참고합니다. 아래 초기 검증 수치는 당시 실행 기록입니다.

## 조작과 재생

- ‘키로 이동’ 문구를 제거했습니다. 최신 조정은 [SVG 캔버스 확장과 재생 컨트롤 확대](EXTENDED_SVG_PLAYBACK.md)를 참고합니다. 실제 SVG 캔버스를 위로 64px 확장하고, 그 안쪽 왼쪽 위에 17px 글자와 큰 삼각형을 겹칩니다. S와의 시각적 정렬을 위한 오른쪽 2px 보정을 유지합니다. 배경과 테두리는 투명하며 클릭 영역은 최소 높이 48px입니다. 축척 막대·단위·시야 문구와 네이티브 키보드 조작은 유지합니다.
- 사용자가 누르면 왼쪽 원자 규모에서 태양까지 이동합니다. 이동 중 버튼은 ‘일시 정지’로 바뀌며, 정지 후 다시 누르면 이어서 재생합니다. 수동 조작 후나 태양 도착 후에는 처음부터 시작합니다. 자동 시작·자동 반복은 없습니다.
- 실제 SI 길이에서 계산한 27개 지수에 정확히 도착해 각각 1.5초 머뭅니다. 이동 시간은 지수 차이에 비례하되 가까운 대상 사이도 최소 700ms를 확보하고, 시작과 끝을 부드럽게 연결합니다. 시간 보간이 과학 데이터나 같은 축척의 크기 비율을 변경하지 않습니다.
- 슬라이더 포인터·키보드, 대상 선택기, 이전/다음 대상은 재생을 멈추고 사용자 조작을 적용합니다. 화면 이동·컴포넌트 해제 시 프레임을 취소하고, 문서가 숨겨지거나 동작 줄이기 설정이 바뀌면 일시 정지합니다.
- 동작 줄이기에서도 사용자가 직접 시작한 재생은 연속 확대·축소하며, 일반 모드보다 이동 시간을 1.5배 확보합니다. 각 대상에서 동일하게 1.5초 머뭅니다. 재생은 자바스크립트가 준비된 뒤에만 사용할 수 있습니다.
- 탐험 페이지의 주소는 일시 정지·종료 시 `replace`로 동기화합니다. 매 프레임 라우팅하거나 방문 기록을 쌓지 않습니다. 재생 중에는 기존 주소가 유지됩니다.

이 기능은 소유자가 직접 요청한 움직임으로, 기존 Taste 보존형 기준과 확대된 계측 패널을 유지합니다. 이전의 자동 움직임 회피 기본값보다 최신 직접 요청을 우선하되, 재생 시작은 사용자에게 맡깁니다.

## 반복 설명 띠를 없애고, 실제 대상으로 시작

`1 → 10`, `10 → 100`, `log₁₀ m` 설명 띠를 제거했습니다. 별도 장식 영역을 추가하지 않고 기존 주제 탐색을 다음 질문으로 정리했습니다.

| 질문                                | 실제 시작 대상 |
| ----------------------------------- | -------------- |
| DNA는 얼마나 가늘까?                | DNA 이중나선   |
| 탁구공에서 고래까지, 얼마나 커질까? | 탁구공         |
| 지구는 태양보다 얼마나 작을까?      | 지구           |

그림은 기존 원본 SVG를 재사용하고 측정 기준·치수는 과학 데이터 객체에서 읽습니다. 각 항목은 해당 대상의 실제 `/scale/?object=…` 주소로 연결합니다. 로그 눈금의 해설과 대상별 측정 기준·출처는 탐험 화면에서 확인합니다. 별도 방법 페이지와 변경 기록 페이지는 소유자의 후속 요청으로 제거했습니다.

## 초기 구현 검증

타입 검사 오류·경고 0개, 단위 테스트 27개, ESLint·Prettier와 정적 빌드가 통과했습니다. 재생 모델의 전체 대상 도착·멈춤·연속성·재개·동작 줄이기·입력 검증을 포함합니다. 웹폰트는 120,988 bytes로 재생성했습니다.

최종 전체 Playwright 44개가 157.0초에 통과했습니다. 실패·건너뜀·불안정 재시도는 모두 0개입니다. 가상 시계로 두 탐험기의 이동·정확한 도착·멈춤·일시 정지·재개·수동 포인터/키보드 우선·태양 종료·재시작·방문 기록·화면 이동 정리를 검증했습니다. 동작 줄이기, 숨김 이벤트에 의한 정지, 실제 출발점의 측정 기준·근삿값·주소도 확인했습니다. 기존 27개 SVG의 실제 축소 비율·반응형 높이 고정·200% 글자 확대·링크·접근성·정적 읽기 검사가 함께 통과했습니다.

별도로 `node scripts/verify-autoplay-live.mjs`를 실행했습니다. 가상 시계를 사용하지 않은 1014×892px 화면에서 시작·원자 도착·원자 머무름·DNA로 이동·DNA 도착의 5개 상태와 일시 정지를 확인했습니다. 원자 머무름의 두 표본은 약 412ms 동안 같은 지수를 유지했습니다. 브라우저 런타임 오류·가로 넘침은 0개입니다. 전체 여정을 실제 시간으로 끝까지 측정했다거나 FPS·Lighthouse 성능 점수를 새로 얻었다는 주장은 하지 않습니다.
