# 원자의 크기 기사 개편 — 2026-10-23

## 요청과 편집

소유자가 제공한 쉬운 개정 원고를 바탕으로 기존 `/articles/atomic-scale/`을 개편한다. 제목·주소·실제 최초 게시 날짜 메타데이터를 보존한다. 초등학생도 읽도록 익숙한 탁구공 → 원자 크기를 정하는 기준 → 나노미터 → 달보다 커지는 탁구공 → 열 배 눈금 → 일상으로 돌아오는 맺음말 순서로 쓴다. 새 글을 추가하거나 기존에 검토한 다른 원자 이야기의 내용을 되돌리지 않는다.

본문은 긴 숫자와 지수 계산을 먼저 제시하지 않는다. 보어 반지름은 수소를 설명하는 기준 길이라고 소개한 뒤 두 배인 약 0.106nm를 설명한다. 원자의 공통 지름이나 단단한 구슬의 가장자리로 일반화하지 않는다. 원자 그림을 이 설명 뒤로 옮기고 기본 표기를 ‘약 0.106nm’로 바꾼다. 네 절의 목차 앵커와 별도의 맺음말을 유지한다.

기존 Editorial Observatory 화면·SUIT·종이색·청록·본문 폭을 보존하는 Taste 적용이다. `DESIGN_VARIANCE=5`, `MOTION_INTENSITY=2`, `VISUAL_DENSITY=4`. 새 3D 엔진·외부 이미지·자동 재생은 추가하지 않고 정확한 길이 비례의 독립 SVG와 읽기 쉬운 HTML 눈금을 사용한다. 계산과 원자료는 기본으로 접힌 메뉴에 보관한다.

## 수치와 원자료

- 기존의 NIST 2022 CODATA PDF와 ITTF Statutes 2025 원문 URL·자료 ID를 보존했다. 새로 확인한 ITTF 소개 글은 조회 도구에서 403을 반환하므로 접근 가능한 기존 규정 §2.3.1의 지름 40mm를 사용한다.
- NIST의 `a₀=5.29177210544e-11 m`, 기준 길이 `2a₀=1.058354421088e-10 m`, 탁구공 지름 `0.04m`는 기존 `science.ts`의 출처가 연결된 SI 객체에서 읽는다. 탐험기 데이터는 변경하지 않는다.
- 길이 비는 `0.04 / (2a₀) ≈ 3.77945225e8`, 본문에서는 약 3억 8천만 배다. 원자 기준 길이를 `0.01m`로 놓는 확대율을 탁구공에 동일하게 적용하면 지름은 `3,779,452.2518m ≈ 3,779.45km`, 읽기 쉬운 표기는 약 3,800km다.
- NASA Moon Fact Sheet에서 달의 체적 평균 반지름 1,737.4km를 확인했다. 두 배 한 평균 지름은 3,474.8km, 도해의 표시는 약 3,475km다. 도해의 지름 비율은 반올림 전 값으로 계산하며 달/커진 탁구공은 약 0.91939249다. 면적·부피·원자 개수 비가 아니다.
- OpenStax Chemistry 2e 6.5에서 원자 크기를 정하는 여러 기준 및 공유 반지름 정의를 확인했다. NNCO의 나노 단위 자료에서 1nm가 1m의 10억분의 1임을 확인했다. 새 두 자료와 NASA를 기존 두 출처에 연결해 하단의 접힌 참고문헌 다섯 개로 보존한다.
- NISE Network의 교육 자료 소개 페이지도 읽기 방향의 참고로 확인했다. 영상 시청이나 해당 자료의 이미지·문장을 복제했다고 주장하지 않는다.

여기서 1cm로 놓은 것은 **원자의 기준 길이 전체인 2a₀**다. 다른 ‘원자는 거의 빈 공간인데’ 기사는 핵의 전하 크기 기준을 1cm로 놓는 별도의 비교다. 새 그림과 도입은 ‘원자의 기준 길이를 1cm로 키운다’고 명시한다.

## 화면과 설명

‘탁구공이 달보다 조금 더 커져요’ 그림에서 커진 탁구공과 실제 달을 같은 선형 비율로 나란히 보여 준다. 크기가 다른 두 SVG의 viewBox·컨테이너 폭을 같게 유지해 실제 화면에서도 원의 지름 비가 보존된다. 장식적인 표면 무늬는 설명용 단순 도형이며 사진이나 지형 지도가 아니다. ‘자세한 계산 보기’에서 상수·단위 환산·길이 비·확대 배율·반올림과 원문 연결을 읽을 수 있다. 전체 출처는 기존 하단 한곳에 접힌 상태로 둔다.

1mm → 1cm → 10cm → 1m는 같은 간격으로 나타내고 다음 단계마다 열 배임을 표시한다. 기존 실제 탐험기의 `ScaleScene`은 그림 크기도 같은 축척으로 계산한다. 따라서 제안 원고의 ‘그림 크기는 실제 비율이 아니다’라는 문장은 **눈금 위의 작은 기호**에 한정해 설명했다. 큰 비교 그림까지 비례가 아니라고 안내하지 않으며, 탐험기를 바꾸지도 않는다.
