# 연속 크기 비교 — v0.1.4

구현·검증일: 2026-10-19 (KST).

홈과 크기 탐험의 SVG를 대상을 바꿔 그리는 방식에서 연속 배율의 비교 화면으로 바꿨습니다. 슬라이더를 오른쪽으로 옮기면 이전 대상의 길이가 줄고, 더 큰 대상의 일부가 화면에 들어온 뒤 전체 형태가 드러납니다. 왼쪽으로 옮기면 반대로 확대됩니다. 기존 로그 눈금자와 원자 기준 표시 높이 고정도 유지합니다.

## 계산과 표시

- 모든 대상의 가로 기준 길이·지름은 `92 × 10^(log₁₀(대상 SI 미터) − 현재 지수)` CSS 픽셀입니다. 한 눈금 이동하면 모든 대상이 10분의 1로 줄어듭니다. 선택 대상이 바뀌는 경계에서 배율을 재설정하지 않습니다.
- 장면 너비를 같은 배율로 환산한 시야 너비와 물리적 기준 자를 함께 표시합니다. 시야 표시의 반올림은 유효숫자 3자리를 사용합니다.
- 원자는 보어 반지름 두 배의 가로 기준선을 비교합니다. 안쪽 궤도 그림은 식별용 상징이며 실제 전자 궤도를 정의하지 않습니다. 탁구대의 비교값은 긴 변이며 그림의 세로 길이를 별도의 과학 측정값으로 주장하지 않습니다.
- 원형 천체와 공은 등록된 대표 지름으로 계산합니다. 그림 배치는 크기 비교용이며 천체 사이의 실제 위치·거리를 나타내지 않습니다.
- 아주 큰 원은 화면에 들어오는 곡면 부분만 수치적으로 안정된 좌표로 투영합니다. 먼 배율의 도형은 옅게 표시합니다. 크기를 작은 범위에 강제로 맞추거나 실제보다 부풀리지 않습니다. 0.15px보다 작은 대상은 렌더링하지 않습니다.
- 기존 출처 있는 7개 대상을 사용합니다. 크기 차이가 큰 구간에 가짜 중간 대상을 추가하지 않았습니다. 장면은 사용자의 입력을 직접 따르며 자동 재생·관성·휠 스크롤 가로채기를 추가하지 않았습니다.

주요 코드: `ScaleScene.svelte`, `scale-scene.ts`, `ScaleExplorer.svelte`. 새 런타임 의존성이나 외부 이미지 없이 Svelte 5와 SVG로 구현했습니다. 방법 페이지와 실제 변경 기록도 갱신했습니다. 원본 과학 측정값·출처는 유지했습니다.

| 타입 검사       | 오류 0·경고 0                |

새 단위 검사는 10배 축소, 모든 대상의 동시 길이 비율, 선택 경계의 연속성, 잘못된 값 거부, 큰 원 투영의 수치 안정성을 확인합니다. 새 Playwright 검사는 홈·탐험에서 실제 SVG 폭이 10분의 1로 줄어드는 것을 0.01px 허용 범위로 확인하고, 탁구대/탁구공의 길이 비율 68.5와 선택 경계의 연속성을 검사합니다.

기존 320~1920px 반응형, 원자 기준 높이 고정, 200% 글자 확대, 키보드·URL·뒤로가기, JavaScript 비활성 읽기와 대표 페이지의 axe 검사도 통과했습니다. 데스크톱·모바일의 원자, 축소된 원자, 들어오는 큰 탁구공, 탁구공, 축소된 탁구공, 탁구대, 지구 단계 캡처 14개를 남기고 주요 단계를 직접 확인했습니다.
