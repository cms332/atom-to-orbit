Official source: https://github.com/sun-typeface/SUIT

License: SIL Open Font License 1.1. The full unmodified notice is in `OFL.txt`.

`A2OSans-Subset.woff2` is a modified glyph subset for A2O's current copy. The internal family and PostScript names are renamed to respect the reserved original name SUIT. It retains variable weights and the original license. The source font is retained in `scripts/fonts/SUIT-Variable.woff2`; `scripts/subset-font.py` reproduces the subset with FontTools and Brotli. Rebuild it when Korean content changes. Missing glyphs fall back to the operating system's font.
